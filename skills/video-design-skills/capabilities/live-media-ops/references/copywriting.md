# 写文案工作流 (Copywriting)

> 配套模板：`assets/script-template.md`。主播调性见 ① 产出的候选人档案；若用户给定了品牌 / 平台 / 受众等约束则一并遵循。

## 1. 先定三件事

1. **平台**：抖音 / 快手 / 视频号 / 小红书（决定时长、结构、语言密度）。
2. **内容类型**：引流 / 种草 / 带货 / 人设 / 剧情。
3. **目标**：涨粉、私域、成交、还是品牌曝光。

## 2. 通用脚本结构（钩子 → 痛点 → 卖点 → 信任 → CTA）

| 段落 | 作用 | 时长占比 | 写法要点 |
|---|---|---|---|
| 钩子 (Hook) | 前 3 秒留住人 | 10% | 反常识 / 冲突 / 悬念 / 直接给利益 |
| 痛点 (Pain) | 共鸣 + 放大需求 | 20% | 具体场景、用户原话 |
| 卖点 (Value) | 产品 / 内容价值 | 40% | 1–3 个核心卖点，配证据 |
| 信任 (Trust) | 消除顾虑 | 20% | 资质 / 数据 / 口碑 / 对比 |
| CTA | 行动指令 | 10% | 关注 / 下单 / 进直播间，单一明确 |

## 3. 分平台要点（可按公司实际偏好调整）

- **抖音**：节奏快、前 3 秒定生死、强情绪、完播率优先。
- **快手**：老铁信任、真实接地气、私域沉淀。
- **视频号**：社交裂变、熟人信任、偏中长干货。
- **小红书**：封面 + 标题党（合规内）、种草笔记体、强搜索词。

## 4. 话术资产

> 下面是**通用底稿**，不是成品。按你的品类替换主语就能用；公司有自有的就覆盖掉。

### 4.1 钩子库（前 3 秒）

| 类型 | 句式 | 例 |
|---|---|---|
| 反常识 | 「[常识] 其实错了，[真相]」 | 「洗面奶不是泡沫越多越好」 |
| 利益直给 | 「[时长] 教你 [省/赚/避] 多少」 | 「30 秒教你避开 90% 人踩的坑」 |
| 自曝冲突 | 「我再也不 [做某事] 了，因为 [原因]」 | 「我再也不买大牌粉底了」 |
| 悬念留白 | 「[过程] 里我差点放弃」 | 「试了 11 家，只有一家我敢推荐」 |
| 场景共鸣 | 「你有没有过 [具体场景]」 | 「刚化完妆出门就花？」 |
| 身份锁定 | 「如果你是 [人群]，这条必须看完」 | 「干皮姐妹先别划走」 |
| 数字清单 | 「[N] 个方法，第 [N] 个最狠」 | 「3 个选品思路，第 2 个帮我清了库存」 |

> 改造方法：把方括号换成你的品类主语。**一条文案只用一个钩子**，别叠加。
> 自检：3 秒内能不能让人知道「这跟我有关」。

### 4.2 卖点支撑（每条卖点必须配证据）

| 说法 | 证据类型 | 不合格的样子 |
|---|---|---|
| 「保湿 12 小时」 | 检测报告 / 实测视频 | 只说「很保湿」 |
| 「30 天可退」 | 平台规则截图 / 客服话术 | 只说「放心买」 |
| 「工厂直发」 | 工厂实拍 / 资质 | 只喊「没有中间商」 |

> 没有证据的卖点 = 空承诺。删掉，或降级成「体验描述」。

### 4.3 CTA 库

| 目标 | 话术 | 备注 |
|---|---|---|
| 关注 | 「关注我，[下一个具体价值]」 | 比「点个关注」有效 |
| 进直播间 | 「今晚 8 点直播间，[具体福利/名额]」 | 给时间 + 具体东西 |
| 下单 | 「下方[位置]，[稀缺/时限]」 | 喊一次就够，别喊三次 |
| 评论互动 | 「评论区打[关键词]，我挨个回」 | 涨互动权重 |
| 私域 | **平台内引导**；站外导流见 `compliance.md` §4 | 别写微信号 |

## 5. 自检清单

- [ ] 平台适配（时长、结构、语气）
- [ ] 前 3 秒钩子是否成立
- [ ] 卖点有证据支撑，无空口承诺
- [ ] 合规：极限词 / 功效宣称 / 导流 已标红排查（通用硬规则，必须标红）
- [ ] CTA 单一明确
- [ ] 与主播调性一致（串联模式）

## 6. 平台细分文案模板（复用外部生态）

抖音 / 视频号 / 小红书等**具体平台**的文案与排版模板，已有成熟第三方 Skill 合集（如 `lqmeter/awesome-social-media-skills`），按需复用即可，见 `references/ecosystem.md`。本文件保留**跨平台通用框架**，不重复造轮子。
