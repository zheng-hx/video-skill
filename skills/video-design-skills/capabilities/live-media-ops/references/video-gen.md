# 生成视频工作流 (Video Gen)

> 配套模板：`assets/brief-template.md`。上游输入为 `copywriting.md` 产出的脚本（讲稿）。
> 本 Skill 为**通用 Skill，不绑定任何 AI 宿主内置工具**。本文件给出「数字人演讲 + 嵌入公司视频」的**生产路线清单、平台原生能力、提示词工程方法**，以及外部生态参考（见 `references/ecosystem.md`）。

## 0. 通用说明（与工具 / 宿主无关）

- 本文件**不假设**运行环境自带生图 / 生视频 / 数字人能力，也**不假设**用户机装了 ffmpeg / torch / 任何本地模型。
- 生图、生视频、数字人由两处之一提供：
  1. **当前 AI 宿主自带能力**：若所在环境提供生图 / 生视频 / 数字人工具，直接调用；
  2. **用户侧外部服务**：否则引导用户使用下列平台（见第 2 节）。
- **真·对口型（嘴与语音对齐）有两条路**：① 数字人平台；② 部分高端视频生成平台已原生支持口型同步（如 Kling 3.0、Veo、即梦）。无这些时只能产出「演示级、不对口型」成片。
- **数字人开源方案（LatentSync / Hallo3 / EchoMimic / MuseTalk …）只作背景知识**：它们通常是数字人平台背后的技术，**不应假设最终用户本地部署**；本 Skill 路线一律走"平台 / 服务"。

## 1. 要交付什么（概念）

一条「虚拟数字人演讲 + 嵌入公司视频」的成片：

- 数字人作为**主讲**（形象 + 讲稿口播）；
- 公司视频作为**嵌入层**（画中画 / 左右分屏 / 模糊背景）；
- 上游：来自 `copywriting.md` 的脚本（即讲稿）。

## 2. 生产路线（按可用条件选择）

### 路线 A：真·对口型（推荐）

唯一能让数字人嘴对上语音的路线，分两类：

**A1 · 数字人平台（对口型 + 真人 / 虚拟形象）**

| 平台 | 特点 |
|---|---|
| HeyGen | 海外，形象 + 讲稿/音频 → 对口型视频，质量高 |
| 腾讯智影 / 数智人 | 国内，企业级，支持定制形象 |
| 即梦 / 可灵 | 国内，生视频 + 数字人能力 |
| 剪映（数字人） | 国内，门槛低，适合短视频 |
| 硅基 / D-ID | 国内 / 海外，口播数字人 API |

流程：确定形象（生图能力出肖像，或平台自带）→ 讲稿驱动 → 出对口型视频 → 嵌入公司视频（平台内合成，或导出后本地剪辑）→ 自检。

**A2 · 支持口型的视频生成平台（原生 dialogue + lip-sync）**

- **Kling 3.0（快手）**：原生对话 + 口型同步，支持多角色对话（≤15s），可用 `[Character A: ...]` 标签锁定角色与口型。
- **Veo（Google）**：对话 / 口型同步，JSON 提示词，同步音效，商业级润色 + 画外音。
- **即梦 / Seedance（字节）**：人物与口型一致性控制，见路线 B 的提示词工程。

> 选择建议：要稳定口播讲解 → **A1 数字人平台**；要电影感 / 多镜头叙事且含对白 → **A2 高端视频生成平台**。

> **默认建议**：短视频口播优先走 A1 的剪映 / 即梦（门槛最低）；企业级定制形象选 HeyGen / 腾讯智影。手上没有任何账号时，先走路线 B 出演示级，别卡在选型上。
> 接入 API / 连接器时再补 `scripts/` 的调用脚本；没有 Key 就不要承诺能调。

### 路线 B：通用生视频演示（无账号，不对口型）

无数字人 / 口型平台时的降级方案，仅作形象 / 氛围演示。

**B1 · 提示词工程（以即梦 / Seedance 2.0 为例，可类推 Kling / Veo）**
把 `copywriting.md` 的脚本转成"可直接粘贴进平台"的结构化提示词：
- **时间戳分镜**：对 ≤15s 视频做逐秒控制，如 `0-3s: 低角度特写…；4-8s: 环绕摇镜…`。
- **负向提示词**：显式排除不想要的元素（水印、字幕、畸形手、脸漂移）。
- **多段拼接**：>15s 自动拆成多段扩展链，附"连续性备注"保持角色 / 场景一致。
- **多模态参考**：用 `@图片1~9`（人物 / 场景 / 首末帧）、`@视频1~3`（运镜 / 动作）、`@音频1~3`（BGM / 音色 / 音效）带入参考。
- **场景策略**：电商广告（产品 360° / 爆炸图）、短剧对话（台词 + 情绪标签 + 音效）、知识科普（4K CGI / 解剖可视化）等。
- 产出 2–3 版提示词供用户选；长片给"多段计划"。

**B2 · 通用生视频（形象动画）**
1. 生图能力出数字人肖像 → 2. 生视频能力把肖像做成动态片段（运动但**不对口型**）→ 3. 配 **TTS 配音 + 字幕**承载讲稿 → 4. 成片合成（可选 ffmpeg，见第 4 节）。

**局限（如实说明）**：数字人**不精确对口型**；属形象 / 氛围演示级；单次时长有限，长片需分段拼接。

### 路线 C：可选 · 自托管整链路（进阶）

**MoneyPrinterTurbo**（GitHub 137k★，MIT）：主题 / 关键词 → 脚本 → 素材（Pexels）→ 配音（EdgeTTS 等）→ 字幕 → 合成；提供 WebUI / API / CLI，Docker 部署。
- 适用：用户想**自托管**一条龙短视频生产，且愿意配 LLM + Pexels Key。
- **非本 Skill 依赖**，仅作可选外部工具参考；它要求 ffmpeg / ImageMagick 等本地环境。

### 路线 D：零工具（什么都没有）

用户机上没 ffmpeg、没数字人平台、没生视频工具、甚至存不了文件时，**不做合成**，交付「制作包」：

- 分镜表（每镜画面 / 口播 / 时长）
- 素材清单（拍什么、去哪找）
- 剪映操作步骤（照着点）
- 生视频提示词（用户之后有平台时能直接用）

完整步骤见 `references/no-tools.md`。

> 这一路线不是凑合。很多情况下，一份能照着剪的制作包，比硬做一个不对口型的成片更值钱。

## 3. 可选：本地合成助手（scripts/composite_digital_human.sh）

仅当用户机装有 `ffmpeg` 时可用，把「数字人层 + 公司视频」合成为一条成片（图层嵌入，不做对口型）。

- 三种布局：`pip`（画中画，默认）/ `split`（左右分屏）/ `background`（模糊背景 + 居中前景）。
- 用法：
  ```bash
  bash scripts/composite_digital_human.sh \
    --presenter presenter.mp4 --company company.mp4 \
    --audio voice.mp3 --layout pip --output final.mp4
  ```
- 脚本开头会检测 `ffmpeg`，缺失即报错并提示安装；参数见脚本内 `--help`。该脚本**非必需**，没有 ffmpeg 时改由剪辑软件或平台内合成完成。

## 4. 通用分镜规范（不变）

每条视频拆字段落入 `assets/brief-template.md`：镜头序号 / 画面景别 / 口播字幕 / 时长 / 素材来源 / 包装花字 / BGM 音效。

## 5. 成片自检

- [ ] 时长符合平台偏好
- [ ] 口播/配音与字幕对齐，无错字
- [ ] 数字人层与公司视频层次清晰、不糊
- [ ] 品牌元素（logo / 色调 / 片尾）齐全
- [ ] 字幕 / 花字可读性（深底浅字或描边）
- [ ] 合规红线已排查（极限词 / 功效宣称 / 导流，必须标红）
