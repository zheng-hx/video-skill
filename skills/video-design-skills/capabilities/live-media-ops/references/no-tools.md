# 零工具降级路线

> 前提：用户机上**什么都没有**——没装 ffmpeg、没有数字人平台账号、没有生视频工具，甚至可能连本地文件都存不了。
> 这不是不能交付，是**交付物形态变了**：从「成片」变成「照着就能做出成片的制作包」。

## 一句话原则

**有工具做成品，没工具给能直接执行的指令。两种都算交付，但绝不能假装做完了。**

## 三种环境，三种交付

| 环境 | 能交付 | 不能交付 | 怎么跟用户说 |
|---|---|---|---|
| 有 ffmpeg + 素材 | 合成好的 `final.mp4` | — | 直接给文件 |
| 只有剪辑软件（剪映等） | 分镜表 + 素材清单 + 逐步骤操作指引 | 成片文件 | 「按这几步剪，10 分钟能出」 |
| 纯对话，什么都存不了 | 完整脚本 + 分镜表 + 提示词 + 操作步骤，全部写在回复里 | 任何文件 | 「内容都在这，复制走」 |

> 判断方式：先问一句「你电脑上有剪映吗 / 能存文件吗」。问完再决定交付形态，别一上来就假设。

## 没有 ffmpeg：用剪映合成

### 画中画（pip）
1. 剪映新建项目，**主轨道**放数字人视频
2. 点「画中画」→ 导入公司视频
3. 双指缩放公司视频到画面右下角，四周留一点边
4. 选中公司视频 → 音量拉到 0（保留数字人的声音）
5. 导出 1080P

### 左右分屏（split）
1. 主轨道放数字人，画中画放公司视频
2. 两段都缩到各占半屏，一左一右
3. 公司视频音量拉 0
4. 导出

### 模糊背景（background）
1. 主轨道放公司视频，加「特效 → 模糊」铺满
2. 画中画放数字人，缩到中间
3. 导出

> 手机剪映和电脑剪映功能名一致，菜单位置不同。描述到功能名就够，别写死按钮坐标。

## 没有数字人平台

按成本从低到高：

1. **图文轮播 + 配音**：剪映「图文成片」，几张图 + TTS 配音，最快
2. **真人出镜**：手机拍，这条最真实，也最不需要工具
3. **只出脚本**：让用户自己拍。别硬凑数字人

> 不要因为「没有数字人平台」就卡住整个流程——视频环节的核心是脚本和分镜，不是那层皮。

## 没有生视频工具

- 用免费素材库（Pexels / Pixabay）配实拍片段
- 用公司现成的视频素材重新剪
- 用 PPT / 图文做「伪视频」，配配音和字幕

## 没有文件写入权限

产物直接写在对话里，用代码块包好，让用户复制。同时说明：

> 「你这环境存不了文件，我把内容都写在这了，复制到本地就行。」

不要反复尝试写文件然后报错——试一次失败就切对话内交付。

## 交付时怎么说（模板）

> 你的机器上没有 [缺的东西]，所以这次不合成成片。我给你的是一份**制作包**：
> 1. 分镜表（每镜画面、口播、时长）
> 2. 素材清单（要拍什么、去哪找）
> 3. 剪映操作步骤（照着点）
>
> 按这个剪，大概 [N] 分钟能出片。要我现在就把分镜写出来吗？
