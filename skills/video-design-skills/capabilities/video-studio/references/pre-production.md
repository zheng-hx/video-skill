# 前期准备：角色卡、参考图与风格锚

> 三件东西必须在正式写提示词之前定死：**角色卡**（这是谁）、**人物参考图**（长这样）、**风格锚**（这是什么世界）。
> 三样错了，提示词写得再好也白搭。

## 1. 角色卡：给模型一个「有脸」的人

### 为什么

文案里说"我有个朋友"，模型看完只知道"要画一个人"——画成路人甲还是主角全看模型心情。**角色卡是给模型画这个人的图纸**，写得越具体，出来越稳。

### 怎么设计

角色卡分三层，缺一不可：

| 层 | 写什么 | 例子（好） | 例子（差） |
|---|---|---|---|
| **身份锚点**（决定"这是谁"） | 五官+发型+发色+年龄+标志性特征（梨涡、眼镜、痣） | 28岁圆脸、暖棕齐肩短发微内扣、斜刘海、杏仁眼、笑起来左脸有梨涡、戴圆框眼镜 | 28岁女性、圆脸、齐耳短发 |
| **造型**（决定"她穿什么"） | 衣服款式+颜色+质感+发型状态 | 米色宽松圆领针织衫，居家感，头发自然微乱 | 米色针织衫 |
| **为什么这么设计**（决定"她为什么是这样"） | 角色设计意图 | 圆框眼镜增加"靠谱过来人"感 | （不写） |

### 身份锚点的几个好模板

| 风格 | 写法模板 |
|---|---|
| AI 漫剧 | 年龄+脸型+发色+发长+发型细节+刘海+眼型+标志性特征（梨涡、泪痣、眼镜） |
| 真人实拍 | 年龄+脸型+发型+发色（挑染？自然？）+眼型+标志性特征（梨涡、痣、眼镜）+大概身高（160+ / 165-） |
| 3D | 年龄+脸型+身材比例（瘦/匀称/微胖）+发型+材质（发质硬/软/卷） |

### 必须写的几个细节

- **发型走向**：内扣/外翻/微卷/自然直——不说的话模型随便画
- **发色**：暖棕/深棕/纯黑/挑染——不说也是随便
- **标志性特征**：梨涡、泪痣、眼镜、虎牙——一个就够，让这个人"有脸"
- **眼镜**（如果有）：圆框/方框/无框/金属框——别只写"戴眼镜"

### 不许做的

- 不许写"二十五六岁女性"这种——模型画出来跟路人甲没区别
- 不许从文案里抄模糊画像然后直接用——那不是角色卡，那是偷懒
- 不许不写角色设计意图——不知道为什么这么设计，说明设计本身没想清楚

## 2. 人物参考图预生成（Step 0.0，强制第一步）

### 为什么先出参考图

靠文字写"26岁圆脸、深棕齐耳直发、梨涡"，模型每次画出来脸都不一样。**先出一张照片级的人物参考图，然后图生视频用这张图**——人物一致性直接锁死。WorkBuddy 两个示例都这么做，不是偶然。

### Step 0.0 流程：先图后视频（**强制，不可跳过**）

```
Step 0.0 文生图（人物参考图）
  ↓ 图片出来后再往下走
Step 1 文生视频（用 Step 0.0 的图做参考）
```

**为什么强制**：
- 人物一致性：五官/发型/服装/身体比例不会漂移
- 风格一致性：照片级参考图定义了光影/色调/质感
- 节省 token：一张好的参考图顶十行形容词

### Step 0.0 人物参考图提示词模板（**照片级**）

```
风格锚（摄影级，比如：照片级写实人像、Arri Alexa Mini 质感、35mm 胶片电影感、日式怀旧电影、低对比度、低饱和度、暖黄偏绿调色、柔焦晕光、浅景深）、
画幅（横版 16:9 或 竖版 9:16，取决于最终视频）、半身中景。

【人物】
年龄 + 脸型 + 眼型 + 标志性特征（梨涡/泪痣/眼镜）、发型走向 + 发色（自然色/挑染/深棕）、发质描述（柔顺/微乱/蓬松）、刘海（斜/八字/无）、化妆描述（唇色/眉毛/眼影——如果是需要化妆的人物）、皮肤质感（可见细微毛孔/自然油光/真实纹理）。

【服装】
款式 + 颜色 + 质感（羊毛针织/纯棉/挂脖/宽松）、无品牌标识与图案。

【环境/光线】
具体场景（出租屋/草原/餐厅包间）、时间（晚上/阴天/黄昏）、光线来源（台灯/阴天散射光/吊灯）、色调（暖黄/冷青/深灰）。

【要求】
人物全脸清晰可辨、五官无遮挡、双手自然下垂且完整可见、细节丰富（织物纹理/发丝纹理）、高动态范围、画面无文字无水印。

反向约束（务必加上，独立成块）：
不要假发感的头发、不要荧光或霓虹粉色头发、不要塑料质感皮肤、不要过度磨皮、不要夸张的大眼睛、不要畸形的手、不要 AI 脸、不要过度锐化。
```

### 参考图要定什么

| 要定的 | 具体写 | 为什么 |
|---|---|---|
| 全脸清晰 | "五官无遮挡" | 视频模型需要看到完整脸才能保持一致 |
| 双手完整可见 | "双手自然下垂且完整可见" | 手部是最容易畸形的部位，先定好 |
| 服装细节 | "黑色无袖挂脖针织上衣" | 视频里衣服不能变 |
| 光线色调 | "暖黄偏绿调色" | 视频里光线不能跳 |
| 发型发质 | "深棕黑色长发、发质柔顺不蓬松、低马尾配八字刘海" | 头发变化 = 人物变了 |

### Step 1 视频提示词里怎么引用参考图

| 平台 | 引用语法 |
|---|---|
| 即梦 | 上传图后自动关联；提示词里不用写 |
| 可灵 | `图生视频` 模式上传参考图；提示词里不用写 |
| Seedance | `@图片1 角色参考` 放在提示词最开头 |
| 混元 | 上传参考图后自动关联 |
| Veo | 上传 reference media |

**关键规矩**：视频提示词里**不用再完整写一遍人物细节**——参考图已经定义了。提示词里只写"主角与参考图为同一人，五官/发型/肤色/身材比例严格一致"就行。

### Step 1 多镜头串起来时的收束

像 WorkBuddy 餐桌示例那样，最后一镜要**收束回参考图的状态**：

> `最终在第 12 秒精确落定于 <Picture 1> 建立的画面`

这能保证整条视频看完之后，人物和场景状态和参考图完全一致。

## 3. 摄影级风格锚

### WorkBuddy 示例的风格锚长什么样

```
照片级写实电影剧照，Arri Alexa Mini 质感，35mm 胶片电影感，日式怀旧电影、低对比度，低饱和度、暖黄偏绿调色、柔焦晕光，浅景深
```

### 我们之前的风格锚

```
暖调、浅景深、手持微晃、低饱和、真实生活感
```

### 差距在哪

| WorkBuddy | 我们的 | 为什么好 |
|---|---|---|
| Arri Alexa Mini 质感 | （没有） | 指定了摄影设备的色彩科学，模型能模拟出特定质感 |
| 35mm 胶片电影感 | （没有） | 指定了镜头焦距和介质，模型知道要出胶片颗粒和光学特性 |
| 暖黄偏绿调色 | 暖调 | 指定了色调偏移方向（黄+绿），模型不会只出"暖橙" |
| 柔焦晕光 | （没有） | 指定了光晕方式，模型知道高光怎么处理 |
| 低对比度 | 低饱和 | 对比度≠饱和度，指定了灰阶范围 |

### 升级后的风格锚模板（分风格写）

**真人实拍感**：

```
[摄影设备] 质感 + [胶片/镜头材质] 感 + [色调偏移：XX偏XX调色] + [对比度/饱和度] + [光晕方式：柔焦晕光/硬边/无] + [景深]
示例：Arri Alexa Mini 质感，35mm 胶片电影感，暖黄偏绿调色，低对比度，低饱和度，柔焦晕光，浅景深
```

**AI 漫剧**：

```
[漫剧类型：日系赛璐璐/美式漫画/水彩漫画] + [线条风格：清晰描边/柔边/粗线] + [饱和度] + [噪点：无/胶片颗粒/水彩纸纹] + [色调偏移]
示例：日系赛璐璐动画风，平涂，清晰描边，高饱和，无真实噪点，柔和暖调
```

**3D 动画**：

```
[渲染引擎：Pixar 风/Blender 风/Unreal 风] + [材质：次表面散射/塑料感/金属] + [光效：体积光/硬边/柔光] + [色调]
示例：写实 3D 渲染，次表面散射皮肤，柔光体积光，低饱和冷调，Unreal Engine 5 质感
```

## 4. 反向约束独立成块（**标红"务必加上"**）

WorkBuddy 的反向约束是独立成块、且标题写"反向约束（务必加上）"。我们之前把 negative 词散在提示词末尾，容易被忽略。现在统一成这样：

```
反向约束（务必加上，独立成块）：
不要假发感的头发、不要荧光或霓虹粉色头发、不要塑料质感皮肤、不要过度磨皮、不要夸张的大眼睛、不要畸形的手、不要 AI 脸、不要过度锐化、不要水印、不要文字、不要多余人物、不要面部漂移、不要塑料感。
```

**为什么独立成块**：模型注意力会被"反向约束（务必加上）"这个标题抓，知道后面的东西不能碰。散在末尾容易被忽略。

> 按风格精准拦哪些词（而不是写"不要 AI 感"这种模糊词）：见 `storyboard-and-prompt.md` §4。
