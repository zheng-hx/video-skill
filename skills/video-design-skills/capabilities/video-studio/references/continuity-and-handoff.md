# 连续性与衔接

> 分镜不是一串孤立提示词。相邻两镜之间断一下，观众就出戏。
> 这里管三件事：人物别换脸、剧情别穿帮、画面接得上。

## 1. 角色卡：长相和造型分开

每个出场角色一张卡，两段各管各的：

| 段 | 管什么 | 例子 |
|---|---|---|
| 身份锚点 | 「还是同一个人」：脸型、五官、发型、肤色、固定标记 | 圆脸、内双、齐耳短发、偏白 |
| 阶段造型 | 「现在什么状态」：服装、配饰、伤妆、年龄 | 米色针织衫、素颜、头发微乱 |

规则：

- 身份锚点在**全片逐字不变**，不许换同义词（「短发」不能一会儿写「齐肩发」）。
- 阶段造型可以按镜头变，但变了要写进状态表，下一镜要能对上。
- 每镜提示词引用角色 id（`host`），不重写一遍外貌描述——重写就会漂。

### 漫剧 / 动画风格：三视图不能少

真人视频一张正脸图基本够；漫剧不行——脸型、发型、发色每镜都最容易漂。

每个主要角色准备三张：

| 视图 | 锁什么 |
|---|---|
| 正脸特写 | 五官比例、眼睛形状、发际线 |
| 90° 侧面 | 侧脸轮廓、鼻子、下巴 |
| 全身正面 | 体型、服装、配饰位置 |

规则：

- 三张图共用同一套身份锚点，服装一致。
- 每镜提示词引用同一角色 id，**不重写外貌**。
- 换服装 / 发型 / 年龄 → 新建一个 Look，不动锚点。

## 2. 连续性状态表

每个镜头一行，写下一镜之前先查上一行：

| 镜号 | 角色在哪 | 穿什么 | 手里拿什么 | 情绪 | 时间/光线 |
|---|---|---|---|---|---|
| s1 | 梳妆台前，画面左 | 米色针织衫 | 手机 | 困 | 清晨，冷光 |
| s2 | 同一位置，画面左 | 同上 | 面霜 | 专注 | 同上 |

状态表是**空间合同**：人物左右站位、朝向、手持物、光向，都在这里对齐。

## 3. 首尾帧链

```text
上一镜尾帧 → 当前镜首帧参考 → 当前镜动作 → 当前镜尾帧 → 下一镜首帧参考
```

- 同一场景、连续动作：**强制**用上一镜尾帧当下一镜首帧。
- 换场景、时间跳跃：不强行复用，改用 `hard_cut` 或 `fade`，但动作结果必须写清。
- 允许运镜造成明显取景变化，**但不许人物左右互换**。

## 4. 衔接合同（每镜必填）

每个非最后镜头写一条：

```json
{
  "from": "s1",
  "to": "s2",
  "mode": "continuous",
  "end_state": "放下手机，抬眼看镜子，右手停在面霜瓶口",
  "next_start_state": "抬眼看向镜子，右手拿起面霜",
  "match_on": ["gaze", "hand_position", "screen_direction", "lighting", "wardrobe"],
  "tail_frame": "media/s1-tail.png",
  "head_frame": "media/s2-head.png",
  "trim_out": 0.3,
  "trim_in": 0.3
}
```

### mode 四选一

| mode | 什么时候用 | 必须写清 |
|---|---|---|
| `continuous` | 同一动作跨镜继续 | 逐项一致的首尾状态 |
| `match_cut` | 构图或动作形状相似，不要求同空间 | 匹配的是哪一形状 |
| `hard_cut` | 叙事连续、画面直接切 | 上一镜结束的事实、下一镜开始的事实 |
| `fade` | 时间或空间跳跃 | 为什么跳、跳多久 |

### 禁止写法

`end_state` 和 `next_start_state` 里写这些词，等于没写：

- 保持连续 / 同上 / 延续上一镜 / 不变 / 照旧

必须写成**可见事实**：谁在哪、朝向哪、手在干什么、光从哪来。

> 注意：「状态表用『同上』简写」可以，但**产出里别复述这两个禁语**（连自检清单里也别写），
> 门禁是按全文判的，写进去就会被判违规。

## 5. 提示词里的首尾句

上一镜提示词最后一段写：

```text
最终停在【结束姿态、目光、双手、持物、位置、光线】。
```

下一镜提示词开头写：

```text
从【与上一镜结束状态逐项一致的起始状态】开始。
```

这两句是给生成模型的，不是给人看的说明——写空话它也会照空话生成。

## 6. 收尾衔接（多段必看）

多段视频最容易烂在结尾：最后一段话说完，画面直接黑掉。

最后一段必须有 `ending`，四选一：

| 类型 | 用法 | 例子 |
|---|---|---|
| `brand_card` | 落版：品牌 + 商品 + 价格/活动 | 白底，商品居中，底部一行字 |
| `cta` | 行动引导：指路 + 停留 | 手指向左下角，字幕「点左下角」 |
| `freeze` | 定格情绪，不推销 | 主角回头笑，画面停 2 秒 |
| `loop` | 首尾同画面，适合循环播放 | 第一镜和最后一镜同一构图 |

规则：

- 收尾至少停留 **1.5 秒**，别让观众看不清落版。
- 收尾画面要和前一段有 handoff，`mode` 写 `match_cut` 或 `hard_cut`。
- 如果最后一段没有台词，`ending` 要有字幕或旁白兜底。
- 如果多条视频是「系列」而不是「一条拆成多段」，**每条都要有自己的 ending**，不能只有最后一条有。

## 7. 裁剪余量

逐镜独立生成时，每条留一点余量给剪辑：

- 开头留 `trim_in` 0.2–0.5 秒；
- 结尾留 `trim_out` 0.2–0.5 秒；
- 只在装配时裁掉，**不覆盖源片段**；
- 长台词、呼吸、动作完成点不要把余量裁光。

## 8. 自检

- [ ] 每个出场角色都有身份锚点，且全片逐字一致
- [ ] 每镜都有状态表行，和上一镜对得上
- [ ] 非最后镜都有 handoff，`end_state` / `next_start_state` 是可见事实
- [ ] 没有写「保持连续 / 同上 / 延续」
- [ ] 最后一段有 `ending`，且停留 ≥ 1.5 秒
- [ ] 源片段保留，成片是独立输出
