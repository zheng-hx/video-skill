# 文案 → 完整故事

> 入口是文案。视频不是把文案念一遍，是把文案里那句「信我」变成一段能看见的故事。
> 这一步的产物是**完整故事**，不是一句话摘要——一句话只配当索引，撑不起分镜。

## 1. 先认入口

| 用户给了什么 | 怎么走 |
|---|---|
| 一段文案（口播稿 / 脚本 / 分条卖点） | 直接进第 2 节 |
| 刚在会话里生成过文案 | 直接用那份，不重写 |
| 有 `script.md` | 读它，取正文 |
| 只有一句话需求（「做个面膜视频」） | 反问一句：「我按你的意思写一版文案，还是你贴文案？」二选一，问完就动 |
| 有产品或链接但没文案 | 先出 60 字简版文案，标 `【简版】`，再往下走；同时说明「要更准的文案，交给 copy-video-studio」 |

**不许做的事**：不读文案就编故事。编出来的故事跟卖点对不上，整条视频就白做了。

## 2. 拆文案：每个成分对应什么画面

### 带货 / 种草类

| 文案成分 | 视频里对应什么 | 镜头职责 |
|---|---|---|
| 钩子（前 3 秒） | 反常画面 / 痛点瞬间 / 结果前置 | 让人停下 |
| 痛点 | 处境镜头：谁在哪、正在遇到什么麻烦 | 让人代入 |
| 卖点 | 演示 / 对比 / 使用过程 | 让人相信有用 |
| 证据（资质、检测、实测、口碑） | 细节特写：包装、成分表、实测画面、评价 | 让人信 |
| CTA | 落版 + 口播收尾 | 让人行动 |

### 择业 / 行业类

择业文案不是「卖东西」，是「让她对号入座」。镜头逻辑完全不同：

| 文案成分 | 视频里对应什么 | 镜头职责 |
|---|---|---|
| 处境 | 一个具体的人在做一件具体的事：下班挤地铁、孩子睡后刷手机、换班时靠在走廊 | 让她觉得「这就是我」 |
| 行业观察 | 工作场景本身：补光灯、提词板、复盘表、镜头前的练习 | 让她看见真实样子 |
| 破除误解 | 对比：外面怎么说的 vs 实际怎么做的 | 打消顾虑 |
| 想聊就来 | 主角看向镜头 / 留白 + 一句轻话 | 让她敢评论 |

**红线**：

- 不出现公司门头、招牌、办公区 logo、招聘海报——一出现就变招聘广告，平台会压。
- 不出现薪资、工牌、合同、面试场景。
- 「主播」只作行业描述，不作文档里的招工邀约。

**镜头气质**：择业视频要「像一个人随手拍的」，不要「像公司宣传片」。手持、自然光、生活场景，比精修布景更可信。

拆完先列一张**信息点清单**，一行一个：

```text
- [钩子] 熬夜后脸发黄 → 画面：早上闹钟按掉，镜子里一张没睡醒的脸
- [卖点] 五分钟提亮 → 画面：涂上脸，出门前的镜子
- [证据] 检测报告 → 画面：报告特写，手指划过数据行
- [CTA] 点左下角 → 画面：落版，商品图和文字
```

## 3. 写完整故事：不是写摘要，是写一段能看见的叙事

一句话故事只是索引。**真正要写的是完整故事**，有开头、有转折、有结尾。

### 四件事必须有

| 要素 | 问自己 |
|---|---|
| 谁 | 这条视频里出现的是谁？多大、做什么、什么状态 |
| 想要什么 | 他此刻最想解决的事是什么 |
| 遇到什么 | 阻碍是什么、为什么现在需要产品 |
| 最后怎样 | 结尾停在哪一帧、情绪落在哪 |

### 写法

- **用现在时**：「她拿起瓶子」，不是「她拿起了瓶子」。
- **能看见**：写动作、表情、光线、道具，不写「她很累」，写「眼下两道青，闹钟按了三次」。
- **有细节**：一个具体的数字、一个具体的时间、一个具体的物件。
- **不写总结**：「最终她找到了解决办法」是总结，不是故事。

### 示例（面膜文案 → 完整故事）

> 早上七点二十，林小雨被闹钟拽起来。昨晚赶方案到一点，镜子里那张脸黄得发灰，眼下两道青。她把冷水扑在脸上，从架子上摸下那支白瓶，挤了一泵胡乱抹在脸上。背包、钥匙、门——出门前她顺手照了下镜子，脚步慢了半拍。刚才那股灰气好像退了一点，脸是亮的。她低头看了眼那支瓶子，塞进包里。手机弹出提醒：今天下单送小样。

这段里：谁（林小雨）、想要什么（赶时间出门但脸太黄）、遇到什么（熬夜 + 没时间）、最后怎样（镜子里脸亮了，瓶子塞进包里）。

### 示例（择业文案 → 完整故事）

> 晚上九点半，林晴把最后一批快递点完，靠在仓库门口的墙边。手机亮着，同城群里有人发「招主播」。她点进去看了两眼，又退出来——上个月同事去了另一家，播了三天，说「对着镜头说不出话」。
>
> 她其实不是不会说话。她能在店里跟阿姨们聊半小时，只是不知道直播到底怎么干。
>
> 她把那条消息截图发给朋友，问了一句：这行到底怎么样。

这段里：谁（林晴）、想要什么（想换个活法但怕踩坑）、遇到什么（信息真真假假）、最后怎样（她开始问人）。

**注意这段跟带货故事的区别**：没有产品、没有卖点、没有落版。它的落点是「她开始问」——视频的 CTA 就是「你也可以问」。

### 示例（择业故事的镜头长什么样）

1. 仓库门口靠墙，手机屏幕亮着，她低着头（处境）
2. **接上一镜**：她低头看着屏幕，手指停住。同一人物，抬头看向店里的货架（信息入口）
3. **接上一镜**：她看着货架，眼神抬起。同一人物，跟阿姨说笑，然后对着手机练说话（真实面）
4. **接上一镜**：她放下手机，眼神还躲着。同一人物，抬头看向镜头，没说话（落点）

注意每一镜开头都不一样，且都写了「接上一镜」——不是各自独立的明信片。

### 补写边界

| 可以补 | 不可以改 |
|---|---|
| 场景、时间、天气 | 卖点本身 |
| 人物外貌、服装、动作 | 价格、优惠、赠品 |
| 情绪、表情、节奏 | 功效宣称、检测结论、数据 |
| 道具、走位、构图 | CTA 的指向 |

补的每一项都要标 `【补写】`。

## 3.5 故事要有事件链，不是一串并列画面

分镜不连贯，根因往往不在分镜，在故事：故事是一组并列的画面，不是「因为 A，所以 B」。

| 类型 | 例子 | 结果 |
|---|---|---|
| 并列（坏） | 她在洗漱。她涂面霜。她出门。 | 三张明信片，切出来各拍各的 |
| 因果（好） | 她发现脸黄 → 所以去涂面霜 → 涂完脸亮了 → 所以她笑了出门 | 一条线，切出来接得上 |

写故事时，每个事件都问一句：**这件事为什么发生？是上一件导致的吗？**

答不上来，就把它删掉，或者换成因果。

**分镜不是把故事切段，是把事件链一段段拍下来。** 每个分镜要回答：这一镜让故事往前走了什么。

## 4. 润色与确认：故事不过，不进提示词

故事写出来只是草稿，必须过一遍再往下走。

### 两种路径

**用户愿意逐项确认**（视频生成贵，推荐）：

一次只问一项，按这个顺序：

1. **人物**：「主角我定成一个每天赶早班的上班族，行不行？」
2. **场景**：「故事放在早上出门前，可以吗？」
3. **情绪走向**：「结尾落在『脸亮了』，不落在『下单』，你看要不要改？」
4. **结尾画面**：「最后一帧是瓶子塞进包里，还是落版？」

用户说「都行」就按默认走，但要在故事里标出来。

**用户不想被问**（文案改起来便宜，可接受）：

直接给完整故事 + 一段「我替你定的」清单，让他在故事上改，别让他答。

### 确认什么

- [ ] 主角对得上目标人群
- [ ] 场景能承载卖点（比如「五分钟」需要早上赶时间的场景）
- [ ] 情绪走向和产品调性一致
- [ ] 结尾停得住，不是话说完就黑屏
- [ ] 卖点、价格、功效、CTA 与文案原文一致

### 改完再走

用户改了故事，就改故事，别重新写文案。故事定稿后落 `assets/story.md`，标「已确认」，再进第 ② 段。

## 5. 故事文件（`output/<日期>-<主题>/story.md`）

```markdown
# 故事 —— 【主题】

- 来源文案：script.md / 用户粘贴
- 类型 / 平台 / 时长 / 风格：【】
- 状态：草稿 / 待确认 / 已确认

## 索引（一句话，只用来快速定位）
【谁】在【什么处境】下，因为【什么】，最后【怎么做了】。

## 完整故事
<完整叙事，长度按内容定>

## 分场
1. 【场景】——【发生什么】——【情绪】
2. 【场景】——【发生什么】——【情绪】
3. 【结尾画面】——【停在哪】

## 人物
- 【谁】：身份【】/ 外貌锚点【】/ 当前造型【】/ 想要什么【】

## 我替你定的（可改）
- 场景：【】
- 主角：【】
- 结尾：【】

## 补写清单
- 【补写】场景：【】
- 【补写】动作：【】
- 【补写】情绪：【】

## 不许动（逐字照原文）
- 卖点：【】
- 价格 / 优惠 / 承诺：【】
- 功效宣称：【】
- CTA：【】
```

## 6. 时长预算：故事定稿再算

```text
总时长 = 台词字数 ÷ 4.5 + 动作时长 + 切镜间隔 + 收尾停留
```

- 中文口播按 4.5 字/秒 估（慢一点按 4，快一点按 5）；
- 每个动作（开盖、挤、涂、转身）留 0.5–1 秒；
- 每次切镜至少留 0.3 秒；
- 收尾定格 / 落版至少 1.5 秒。

超了按顺序砍：**砍动作 > 砍台词 > 加时长**。不许悄悄压语速。

## 7. 自检

- [ ] 完整故事有开头、转折、结尾，长度按内容定，不凑字也不删细节
- [ ] 主角处境能解释「为什么现在需要它」
- [ ] 每个卖点、证据、CTA 都在故事里有对应画面
- [ ] 补写项都标了 `【补写】`
- [ ] 卖点、价格、承诺、CTA 与原文逐字一致
- [ ] 用户确认过，或明确标了「我替你定的」
- [ ] 时长预算算过了，没有硬压
