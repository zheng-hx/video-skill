# 文案 → 完整故事

> 入口是文案。视频不是把文案念一遍，是把文案里那句"信我"变成一段能看见的故事。
> 这一步的产物是**完整故事**，不是一句话摘要——一句话只配当索引，撑不起分镜。

## 1. 先认入口：展开模式 vs 从零补写模式

**先读文案，判断它是哪种：**

| 文案类型 | 判断依据 | 走哪个模式 |
|---|---|---|
| **故事型**（copy-video-studio 默认产出） | 有主角、有处境、有转折、有落点；不是钩子→痛点→卖点的广告结构 | **展开模式**：接骨架长肉，不重写主线 |
| **广告型**（带货/种草） | 钩子→痛点→卖点→证据→CTA；没有具体人物故事 | 从零补写模式：编故事承载卖点 |

**怎么判断**：文案里有没有一个"**具体的人**"在做一件"**具体的事**"？有就是故事型，没有就是广告型。

> copy-video-studio 默认产出故事型文案，所以**大多数情况走展开模式**。只有带货/种草类文案可能是广告型，走从零补写。

## 模式 A：展开模式（故事型文案 → 完整故事）

### A.1 识别文案里的故事骨架

故事型文案已经有了骨架，拆成四块：

| 骨架块 | 文案里的样子 | 视频里对应什么 |
|---|---|---|
| 主角 | 一个具体的人（我、我一个朋友、那个姑娘） | 角色卡：身份锚点 + 阶段造型 |
| 处境 | 她在做什么（投简历、躺出租房、刷直播） | **固定场景**（同一场景演完，不换） |
| 转折 | 她发现了什么 / 试了什么 | 中间事件链：因为 A 所以 B 所以 C |
| 落点 | 结尾钩子（评论区说一声、私信你） | 最后一镜：定格 / 看向镜头 / 留白 |

**不许做的事**：重写主线、换主角、换转折、换落点。文案里说的是"投简历没人回→试了直播→够交房租"，视频里就必须是这条线。

### A.2 展开：补细节、补画面、补事件链——**但场景尽量不变**

这是我之前写错的地方：展开不是换场景，是**在同一场景里补人物状态、补时间变化、补画面细节**。

| 补什么 | 怎么补 | 核心规则 |
|---|---|---|
| **场景** | 选一个，演完三幕 | **尽量只换时间、不换地点**。出租屋 = 起→承→转→合都在出租屋；工位 = 全程工位。换场景只有在"转机确实发生在别处"时才允许 |
| **人物状态变化** | 补表情、补动作、补物品变化（头发、衣服、桌上东西、手机内容） | **用同一个人物在同一个位置的状态变化体现时间流逝**，不是换个地方演 |
| **事件链** | 每个动作问"为什么"，补因果 | 不是"她刷了手机"，是"她躺了三天没动→手痒了拿起手机→刷到那个姑娘" |
| **声音** | 人物台词（对着镜头说）或字幕卡 | **不用画外音旁白**——要么人物自己说，要么画面飘字幕 |

### 三幕在同一场景里怎么演

| 幕 | 场景 | 人物状态 | 画面钩子点 |
|---|---|---|---|
| **起** | 出租屋 | 余额 127.6，窗帘拉着一半，墙上有失败截图 | 手指按灭屏幕×4、盯着"暂不匹配"看三秒 |
| **承** | **还是同一个出租屋** | 三天过去了，窗帘全拉着，外卖盒堆在门口，泡面筷子还在 | 手机屏幕还亮着但没人碰、外卖盒堆积是时间流逝的证据 |
| **转** | **还是同一个出租屋** | 手痒拿起手机刷，刷到一个姑娘在镜头前说话 | 手指从悬着变成指尖点在屏幕上没动——**同一个手指，动作变了** |
| **合** | **还是同一个出租屋，同一个位置** | 过了一段时间，对着手机镜头坐直说话 | 之前揉简历的手现在举着手机笑；之前眼尾下垂现在梨涡露出来——**同一个手、同一张脸，表情变了** |

**核心**：起承转合不是四个场景，是**同一个人在同一个位置，从沮丧到转机到释然的变化**。变化的是她，不是环境。

### A.3 人物台词 vs 字幕卡 vs 旁白

视频里的声音只有两种，**没有第三种**：

| 方式 | 什么时候用 | 怎么写进提示词 |
|---|---|---|
| **人物台词**（默认） | 人物对着镜头说话，是故事的一部分 | 提示词里写"说：'我去年辞了干了三年的...'"，带引号 |
| **字幕卡** | 情绪性画面，不需要声音（比如"余额 127.6"的特写） | 提示词里写"画面下方飘字幕：'127.6'" |
| ~~画外音旁白~~（禁止） | — | **不许写**。画外音让承接断裂（旁白在说 A，画面在演 B），视频模型也出不好画外音 |

### A.4 不许改的（逐字照文案原文）

| 不许改 | 为什么 |
|---|---|
| 主角身份（谁、做什么的） | 文案里已经定了，改了就跑题 |
| 核心转折（她看到了什么、试了什么） | 视频是文案的视觉化，不是另起炉灶 |
| 落点钩子（结尾让人做什么动作） | CTA 逐字保留 |
| 限流词处理结果 | copy-video-studio 已经替换过，别换回去 |

补的每一项都标 `【补写】`。

### A.5 展开后示例

**文案原文**（copy-video-studio 产出的故事型文案）：

> 我朋友投了三十份简历，回的三个，都说是"不合适"。后来她刷到别人做直播，想试试。播了一个月，够交房租。你要也想试试，评论区说一声。

**展开后的完整故事**：

> 晚上十点，【补写】城中村出租屋的灯亮着。【补写】二十五六岁的姑娘齐耳短发，穿洗得发白的卫衣，【补写】趴在书桌前翻手机。
>
> 简历投了三十份。手机屏幕亮了三次，每次点开都是"感谢您的投递，我们认为您与岗位暂不匹配"。
>
> 她把手机扣在桌上，盯着天花板发了一会儿呆。然后又捡起来，开始刷短视频。
>
> 【补写】刷到一个姑娘，镜头前说话有点生涩，但脸上的笑是真的。她刷了好几条——这是第三个月的那条，弹幕里有人说"我来的时候也是这样"。
>
> 她坐起来，对着手机镜头试了一个表情，又放下。
>
> 【补写】画面停在她手指悬在屏幕上方的那一刻。【补写】字幕出来：想试试？评论区说一声。

> 这段里：主角（二十五六岁姑娘）、处境（出租屋投简历）、转折（刷到别人的直播）、落点（评论区说一声）——**全是文案原文**，没改。补的全标了【补写】。

## 模式 B：从零补写模式（广告型文案 → 完整故事）

### B.1 拆文案：每个成分对应什么画面

| 文案成分 | 视频里对应什么 | 镜头职责 |
|---|---|---|
| 钩子（前 3 秒） | 反常画面 / 痛点瞬间 / 结果前置 | 让人停下 |
| 痛点 | 处境镜头：谁在哪、正在遇到什么麻烦 | 让人代入 |
| 卖点 | 演示 / 对比 / 使用过程 | 让人相信有用 |
| 证据（资质、检测、实测、口碑） | 细节特写：包装、成分表、实测画面、评价 | 让人信 |
| CTA | 落版 + 口播收尾 | 让人行动 |

### B.2 写完整故事：不是写摘要，是写一段能看见的叙事

一句话故事只是索引。**真正要写的是完整故事**，有开头、有转折、有结尾。

#### 四件事必须有

| 要素 | 问自己 |
|---|---|
| 谁 | 这条视频里出现的是谁？多大、做什么、什么状态 |
| 想要什么 | 他此刻最想解决的事是什么 |
| 遇到什么 | 阻碍是什么、为什么现在需要产品 |
| 最后怎样 | 结尾停在哪一帧、情绪落在哪 |

#### 写法

- **用现在时**："她拿起瓶子"，不是"她拿起了瓶子"。
- **能看见**：写动作、表情、光线、道具，不写"她很累"，写"眼下两道青，闹钟按了三次"。
- **有细节**：一个具体的数字、一个具体的时间、一个具体的物件。
- **不写总结**："最终她找到了解决办法"是总结，不是故事。

#### 示例（面膜文案 → 完整故事）

> 早上七点二十，林小雨被闹钟拽起来。昨晚赶方案到一点，镜子里那张脸黄得发灰，眼下两道青。她把冷水扑在脸上，从架子上摸下那支白瓶，挤了一泵胡乱抹在脸上。背包、钥匙、门——出门前她顺手照了下镜子，脚步慢了半拍。刚才那股灰气好像退了一点，脸是亮的。她低头看了眼那支瓶子，塞进包里。手机弹出提醒：今天下单送小样。

这段里：谁（林小雨）、想要什么（赶时间出门但脸太黄）、遇到什么（熬夜 + 没时间）、最后怎样（镜子里脸亮了，瓶子塞进包里）。

#### 补写边界

| 可以补 | 不可以改 |
|---|---|
| 场景、时间、天气 | 卖点本身 |
| 人物外貌、服装、动作 | 价格、优惠、赠品 |
| 情绪、表情、节奏 | 功效宣称、检测结论、数据 |
| 道具、走位、构图 | CTA 的指向 |

补的每一项都要标 `【补写】`。

## 公共规则（两种模式都要）

### 3.5 故事要有事件链，不是一串并列画面

分镜不连贯，根因往往不在分镜，在故事：故事是一组并列的画面，不是"因为 A，所以 B"。

| 类型 | 例子 | 结果 |
|---|---|---|
| 并列（坏） | 她在洗漱。她涂面霜。她出门。 | 三张明信片，切出来各拍各的 |
| 因果（好） | 她发现脸黄 → 所以去涂面霜 → 涂完脸亮了 → 所以她笑了出门 | 一条线，切出来接得上 |

写故事时，每个事件都问一句：**这件事为什么发生？是上一件导致的吗？**

答不上来，就把它删掉，或者换成因果。

**分镜不是把故事切段，是把事件链一段段拍下来。** 每个分镜要回答：这一镜让故事往前走了什么。

### 4. 润色与确认：故事不过，不进提示词

故事写出来只是草稿，必须过一遍再往下走。

#### 两种路径

**用户愿意逐项确认**（视频生成贵，推荐）：

一次只问一项，按这个顺序：

1. **人物**："主角我定成一个每天赶早班的上班族，行不行？"
2. **场景**："故事放在早上出门前，可以吗？"
3. **情绪走向**："结尾落在'脸亮了'，不落在'下单'，你看要不要改？"
4. **结尾画面**："最后一帧是瓶子塞进包里，还是落版？"

用户说"都行"就按默认走，但要在故事里标出来。

**用户不想被问**（文案改起来便宜，可接受）：

直接给完整故事 + 一段"我替你定的"清单，让他在故事上改，别让他答。

#### 确认什么

- [ ] 主角对得上目标人群
- [ ] 场景能承载卖点 / 核心事件
- [ ] 情绪走向和内容调性一致
- [ ] 结尾停得住，不是话说完就黑屏
- [ ] 卖点、价格、功效、CTA 与文案原文一致
- （展开模式）文案里的主角、转折、落点全保留了

#### 改完再走

用户改了故事，就改故事，别重新写文案。故事定稿后落 `assets/story.md`，标「已确认」，再进第 ② 段。

### 5. 故事文件（`output/<日期>-<主题>/story.md`）

```markdown

- 来源文案：script.md / 用户粘贴
- 模式：展开（故事型） / 从零补写（广告型）
- 类型 / 平台 / 时长 / 风格：【】
- 状态：草稿 / 待确认 / 已确认

## 索引（一句话，只用来快速定位）
```

### 6. 时长预算：故事定稿再算

```text
总时长 = 台词字数 ÷ 4.5 + 动作时长 + 切镜间隔 + 收尾停留
```

- 中文口播按 4.5 字/秒 估（慢一点按 4，快一点按 5）；
- 每个动作（开盖、挤、涂、转身）留 0.5–1 秒；
- 每次切镜至少留 0.3 秒；
- 收尾定格 / 落版至少 1.5 秒。

超了按顺序砍：**砍动作 > 砍台词 > 加时长**。不许悄悄压语速。

### 7. 自检

- [ ] 模式选对了（故事型→展开 / 广告型→从零补写）
- [ ] 完整故事有开头、转折、结尾，长度按内容定，不凑字也不删细节
- [ ] 主角处境能解释"为什么现在需要它"
- [ ] 每个信息点都在故事里有对应画面
- [ ] 补写项都标了 `【补写】`
- [ ] 卖点、价格、承诺、CTA 与原文逐字一致
- [ ] （展开模式）文案里的主角、转折、落点没改
- [ ] 用户确认过，或明确标了"我替你定的"
- [ ] 时长预算算过了，没有硬压
