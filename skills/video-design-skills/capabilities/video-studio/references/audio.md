# 声音与台词

> 视频是画面，台词是声音。**两样分开交付**——别指望视频模型自带台词。

## 1. 三样东西分开管

| 东西 | 谁产 | 交付形态 |
|---|---|---|
| 台词 | 文案定稿 | 逐句文本 |
| 配音 | TTS / 真人 / 数字人平台 | 音频文件（mp3 / wav） |
| 字幕 | 剪辑时加，或自动识别 | srt，或直接烧字 |

**视频生成模型大多不出台词**。文生视频出来是哑的，这不是 bug，是常态。

**但画面里必须「在说话」**——这一点跟模型支不支持声音无关：

- 支持声音：写对白，一次出。
- 不支持：也要写「嘴唇微动，正在说话」，至少让人张嘴，声音后配。
- 画面没写说话 → 人站着嘴不动 → 后配音像在给木头人配音，整条废。

所以 `line` 和「正在说话」是两件事，都要有。

## 2. 配音路线

| 路线 | 适合 | 怎么做 |
|---|---|---|
| TTS | 口播、带货、科普 | 剪映「文本朗读」/ 豆包 TTS / 讯飞 |
| 真人录 | 人设、剧情、择业 | 手机录，安静房间，离麦一拳 |
| 数字人平台 | 要精准口型 | 即梦 / HeyGen / 腾讯智影，讲稿驱动 |
| 平台原生音频 | Veo 等支持 | 提示词里写【声音】 |

## 3. 口型怎么办

| 情况 | 做法 |
|---|---|
| 要精准对口型 | 数字人平台，或支持 dialogue 的视频模型 |
| 口型可以不对 | 走画外音 + 字幕——最常见，也最稳 |
| 漫剧 | 不追口型，配音 + 字幕 |

**别硬追**：不对口型的画外音，比口型对不上的假人对口型更让人接受。

## 4. 字幕规范

- 一句一行，**不超过 14 字**。
- 数字用阿拉伯数字（「28 天」不是「二十八天」）。
- 少用标点，靠断行断句。
- 关键词可以加粗或变色，但别满屏花字。

## 5. 分镜里要填什么

```json
{
  "line": "熬夜脸发黄？",
  "voice": "tts_female_warm",
  "silent": false
}
```

- `line`：台词原文，一句一条。
- `voice`：配音标识，给 TTS 用（女声/男声、语速、语气）。
- `silent`：没有台词的镜头标 `true`（空镜、纯画面）。

**`line` 和 `silent` 二选一，不能都空。**

## 6. 交付时怎么给

分镜和提示词之外，单独给一段：

```text
【台词 / 配音】
1. 熬夜脸发黄？—— 画外女声，疲惫
2. 每天早上五分钟—— 画外女声，平缓
3. 气色肉眼可见地亮—— 画外女声，上扬
（配音方式：剪映文本朗读，女声，语速 1.0）
```

用户拿去粘 TTS，或者自己念。
