# 画面红线

> 文案查的是「词」，这里查的是「画面里会出现什么」。
> 词写干净、画面里一个二维码，整条照样废。

## 1. 七类必拦

| 类别 | 画面里长什么样 | 后果 |
|---|---|---|
| 他牌 / 竞品 logo | 包装、背景货架、衣服上的其他品牌标识 | 侵权、广告法、可能下架 |
| 二维码 / 联系方式 | 角落二维码、微信号、手机号、店铺门牌 | 站外导流，直接限流 |
| 真人未授权 | 能认出来的真人脸、身体 | 肖像权，投诉即下架 |
| 儿童出镜 | 未成年人的脸或身体 | 需监护人书面授权 |
| 医疗对比 | 用前 / 用后对比、伤口、血、病灶特写 | 医疗广告红线 |
| 擦边 / 低俗 | 暴露、暗示性动作、暧昧镜头 | 低俗处罚 |
| 伪证 | 假检测报告、假证书、假销量截图 | 虚假宣传，可封号 |

## 2. 在提示词里怎么防

- **负向词必须含**：`其他品牌logo、二维码、文字水印、手机号、微信号、店铺招牌`
- **产品要干净**：拍自己的产品用白底、不露包装上的其他标识，或写「无品牌标识」
- **要真人**：写「授权真人出镜」，并在 `meta.authorization` 里标 `authorized`
- **要儿童**：先拿到监护人授权，标 `guardian_authorized`，否则不许生成
- **要对比**：不做医疗前后对比，改「使用过程」或「体验描述」

## 3. 授权表（storyboard.json 的 meta.authorization）

```json
{
  "real_person": "authorized | not_applicable | pending",
  "minor": "not_applicable | guardian_authorized | pending",
  "brand_logo": "owned | licensed | none",
  "medical_claim": "none | qualified"
}
```

规则：

- 任一字段为 `pending` → **不许生成**，先问用户。
- `real_person` 不是 `not_applicable` 就必须是 `authorized`。
- `minor` 是 `guardian_authorized` 才允许出现儿童。

## 4. 检查顺序

画面红线不是生成后检查，是**写提示词时就拦**：

1. 先看这条视频里会不会出现人 / 儿童 / 别人的品牌 → 决定授权字段。
2. 负向词先把七类写进去。
3. 生成前过一遍 `check-storyboard.py`，它会拦授权 `pending` 和缺负向词。
4. 生成后再人眼扫一遍：角落、背景、衣服、包装。
