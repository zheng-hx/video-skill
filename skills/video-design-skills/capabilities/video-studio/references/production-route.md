# 生产路线与交付

> 三段流程的最后一段：把分镜和提示词变成能用的东西。
> 能不能真生成，取决于宿主有没有能力；没有就别装，给交接包。

## 1. 能力探测：从近到远，不能跳

| 顺序 | 先看什么 | 有就怎么办 |
|---|---|---|
| ① 宿主自己 | 本会话有没有生图 / 生视频 / TTS 工具 | 直接调，文件落 `media/`，回填路径 |
| ② 外包给别的 AI | 宿主能不能直调 API，或控制用户已登录的浏览器 | 按 `references/outsourcing.md` 的契约外包，拿回来验一遍 |
| ③ 用户手动喊话 | 他没有 API、宿主也控制不了浏览器 | 给他一段能直接复制的话（`assets/ask-ai.md`） |
| ④ 都没有 | — | 制作包 / 拍摄清单 |

规则：

- **先看自己**：别一上来就让用户去开 App，宿主能出就直接出。
- **再看能不能外包**：宿主有 API Key 或浏览器控制权时，直接让别的 AI 干活，比让用户手动复制强。
- **再看他手上的**：他天天用的豆包、即梦，比「装个宿主」熟得多，让他喊这些 AI 帮忙最省事。
- **最后才降级**：都没有才给制作包，而且要说明「这次出不了成片」。
- 问的时候只问一句，别列清单：**「你手机上有豆包、即梦、剪映吗？有哪个？」**

## 2. 宿主原生：按顺序来，别跳

```text
① 角色关键帧（每个角色一张正脸 + 一张全身）
② 每镜首帧 / 尾帧
③ 逐镜视频
④ 配音 / 音效
⑤ 字幕
⑥ 装配
```

规则：

- **先生图再生成视频**：没有关键帧锁脸，视频里的脸会每镜一漂。
- 每生成一个文件就落盘到 `media/`，并在 `storyboard.json` 里回填路径。
- 单镜重跑只替换该镜，不动已通过镜头。
- 生成前先问一句「这一步要花额度，继续吗」——别默默烧钱。

## 3. 外部平台交接包

用户用即梦 / 可灵 / 剪映 / HeyGen 时，给这五样：

1. **每镜提示词**：可直接复制，按镜号排好
2. **目标工具假设**：写明「按 X 平台语法写的，换平台要改哪几处」
3. **生成顺序**：先出关键帧 → 再出视频 → 最后配音
4. **文件命名**：`s1.png` / `s1.mp4`，回填到 `media/`
5. **回填说明**：生成完把文件放回哪、怎么更新状态

不写「已生成」「可播放」这类话。交付的是**提示词包**，不是成片。

## 4. 零工具制作包

参考 `copy-video-studio/references/no-tools.md` 的剪映步骤，交付：

- 分镜表（每镜画面 / 口播 / 时长）
- 素材清单（拍什么、去哪找）
- 剪辑步骤（照着点）
- 每镜提示词（用户之后有平台能直接用）

## 5. 授权与边界

- 涉及真人、儿童、品牌、功效、价格 → 先确认授权和口径，不许默认。
- 付费生成（额度、积分、API Key）→ 先说明、得到同意再调。
- 没有能力 / 没有授权 → 保留纯本地方案，明确说「这一步出不了成片」。

## 6. 路线自检

- [ ] 探测过宿主能力，没有凭空假设
- [ ] 宿主原生：先关键帧后视频，文件已回填
- [ ] 外部交接：五样齐全，没宣称已生成
- [ ] 零工具：制作包能照着做出来
- [ ] 付费生成前问过用户
