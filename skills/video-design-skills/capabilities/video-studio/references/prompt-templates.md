# 平台提示词模板

> 各平台的官方语序和写法差异。写之前先确认目标平台，**别串台**。
> 字段骨架（共享 / 独有）见 `storyboard-and-prompt.md` §7；外部资源库见 `prompt-resources.md`。

## 1. 通用语序：重要信息放前面

模型注意力是前几词权重最大。推荐顺序：

```
风格锚 → 身份锚点（主体长什么样）→ 光线基调 → 镜头（景别+运镜）→ 主体动作 → 场景细节 → 质感 → 约束 → 负向
```

## 2. 平台语法差异

| 平台 | 结构 | 单次时长 | 多镜头支持 | 特殊写法 |
|---|---|---|---|---|
| **即梦** | 镜头类型 + 情绪 + 说话状态 + 动作 + 背景 | 5–15 秒 | ✅ 一条里写多镜头 | 中文优先，支持 `@图片N` |
| **可灵** | 主体 + 动作 + 场景 + 镜头 + 光线 + 氛围 | 5–10 秒 | ✅ Auto Multi Shot（自动切） | 中英文都可；`[角色名]` 引用 |
| **混元** | 主体 + 动作 + 运镜 + 光线 + 风格 + 声音 | 5–15 秒 | ✅ 一条多动作按时间排列 | 中文友好；直接写声音/字幕指令 |
| **Seedance** | 时间轴分段 | ≤15 秒 | ✅ 时间轴 `[0-3秒]...` | `@图片` / `@视频` / `@音频` 参考 |
| **Veo / Sora** | 一段连贯英文长句 | ≤8 秒 | ❌ 单镜头 | 自然语言，少堆参数 |

> 时长和参数以官方文档为准，这张表只用来提醒「别串台」。

## 3. 即梦（jimeng）

来源：即梦官方文档 + 火山引擎实践指南

```
推荐（口播/说话类）：
镜头运动 + 主体情绪 + 说话状态（说话/微笑/沉默）+ 具体动作 + （可选）背景事件/其他角色

基础（非口播）：
主体 + 背景 + 镜头 + 动作

多镜头连贯：
镜头1 + 主体 + 动作1 + 镜头2 + 主体 + 动作2 ...
（即梦支持一条里写多个镜头，但总时长不能超 15 秒）
```

**即梦好例子**：

```
中景缓慢推近，年轻女子坐在窗边心情平静，轻轻端起咖啡杯，微笑着对镜头说话。旁边男孩悄悄看着她，时不时转向镜头笑笑。背景灯光柔和，暖色调，浅景深。
```

**即梦差例子**（别这样写）：

```
咖啡杯 女子 窗边 微笑 端起 镜头推近 暖色调 柔和灯光 坐在 心情平静
（关键词堆叠，模型不知道谁在做什么）
```

## 4. Seedance 2.5

来源：Seedance 2.5 提示词指南（火山方舟）

```
必填 8 元素：
1. 主体（precise subject）—— 谁
2. 动作细节（action details）—— 做什么，怎么做
3. 场景环境（scene and environment）—— 在哪
4. 光线色调（lighting and color tone）—— 什么光、什么色
5. 镜头运动（camera movement）—— 什么景别、什么运镜
6. 视觉风格（visual style）—— 真人/漫剧/3D
7. 图像质量（image quality）—— 浅景深/胶片颗粒/高分辨率
8. 约束（constraints）—— 必须保持不变的部分

写法：写成连接的句子，不是关键词列表。
每镜头一个主动作，最多一个微动作。
```

## 5. 可灵（Kling）

来源：[Kling 官方文生视频指南](https://kling.ai/quickstart/text-to-video-prompt-guide) + [进阶技巧](https://kling.ai/blog/ai-video-prompts-advanced-techniques-realistic)

```
推荐结构（6 元素）：
主体（subject）+ 动作（movement）+ 场景（scene）+ 镜头语言（camera）+ 光线（lighting）+ 氛围（atmosphere）

示例：
A young woman sitting on a worn couch in a dimly lit rental apartment. She slowly picks up her phone from the table, thumbs the screen, stares blankly for three seconds, then presses the screen off. Warm desk lamp light from upper left, cool night street light through the half-drawn curtain. Handheld camera slowly pushes in to medium close-up. Low saturation, film grain, realistic texture.

多镜头自动模式（Auto Multi Shot）：
直接在提示词里描述场景 + 对话 + 镜头覆盖 + 视觉节奏，模型自己切角度和景别。
比如："年轻女孩在出租屋，先给她手指按灭屏幕的特写，然后中景看她蜷在被子里发呆，然后近景推到手机屏幕亮了——屏幕里是一条短视频。柔和暖光。"
（可灵会自动判断需要几个镜头，每个用什么景别）
```

**可灵 5 条进阶技巧**（官方验证）：

1. **重要元素放最前面**——模型开头权重最大，主体和第一个动作必须在最前
2. **别写矛盾光线**——"bright sunny day" + "moody lighting" 这种，选一个保持一致
3. **别太长**——详细但简洁，太长模型忽略后面
4. **动作描述要具体**——"presses the screen off slowly three times" 比 "uses phone" 好
5. **支持中文和英文**——英文在细节描述上更稳定，中文在风格词上更灵活

## 6. 混元（腾讯 HunyuanVideo）

来源：[腾讯混元官方页面](https://hunyuan.tencent.com/video/) + [腾讯云生视频调用指南](https://cloud.tencent.com/document/product/1823/137202)

```
推荐结构（中文友好，原生支持中英文）：
主体 + 动作 + 运镜 + 光线 + 风格 + 声音（可选）

示例（中文）：
俯视角度，一位深色略带凌乱长卷发的年轻中国女性，佩戴珍珠项链和金色耳环，头发被风吹散。她微微抬头望向天空，神情哀伤眼中含泪。柔和的侧光从窗边打来，背景是灰色的出租屋墙面。手持镜头缓慢推近到特写。真实生活感，低饱和。画面里有微弱的窗外风声。

图生视频公式（混元专属）：
运动 + 运镜（因为图片已经定下了主体和风格）
比如："身体轻微摇摆，右手缓缓抬起遮住嘴巴。固定镜头，轻微呼吸感。"

多镜头：
混元支持连续运镜和动作组合，一条提示词里可以写多个动作，但要按时间顺序排列。
```

**混元特殊能力**：

- **强指令响应**：能解析复杂语义（光影、构图），自动映射至视频参数
- **声音指令**：可以在提示词里直接写声音——"画面里有微弱的窗外风声""瀑布轰鸣""脚步踩木地板"
- **文字渲染**：直接写"屏幕下方浮字幕 XXX"，模型能生成文字
- **人像驱动**：上传参考图驱动人物动作（API 层面）

## 7. 各平台提示词公式速查

| 平台 | 写提示词时的顺序 |
|---|---|
| 即梦 | 镜头运动 → 情绪 → 说话状态 → 具体动作 → 风格 → 光线 → 质感 |
| 可灵 | 主体（开头最重要）→ 动作 → 场景 → 镜头 → 光线 → 氛围 |
| 混元 | 主体 → 动作 → 运镜 → 光线 → 风格 → 声音（可选） |
| Seedance | 主体 → 动作 → 场景 → 光线 → 镜头 → 风格 → 质量 → 约束 |

## 8. 关键规矩

1. **一镜一个主动作**。超过两个主动作，模型大概率只出前一个。
2. **主体第一个动作不能省略**。"端起咖啡杯"比"做什么动作"好。
3. **不要写"让模型自由发挥"**。模型不知道你要什么，每一步都要写清楚。
4. **先写镜头，再写主体**。即梦和 Seedance 都是镜头→主体的顺序。
5. **负面词别超过 15 个**。写太多模型会忽略重点。
