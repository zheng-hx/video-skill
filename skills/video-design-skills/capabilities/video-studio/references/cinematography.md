# 镜头、光影与声音模板库

> 这份是「拿来就能用」的模板库，不是方法论。
> 写提示词时从这里挑词、套公式；挑完再对照 `prompt-anti-patterns.md` 排一遍。

## 1. 全局前置块（每条片开头统一挂一次）

同一支片子里，这一段逐字不变，放在每条提示词最前面：

```text
【画质】8K 超高清，超高细节纹理，电影级渲染
【摄影机】ARRI Alexa 65 质感的动态范围
【镜头】50mm 标准定焦，f/2.8 浅景深，焦点锁在主体
【胶片】柯达 5219 胶片质感，细腻颗粒，色彩柔和不过锐
【制式】24fps，2.39:1 宽银幕（竖屏短视频改成 9:16）
【硬性约束】无畸变、无穿帮、无多余空镜；人物五官全程一致，服装发型配饰前后不改；
手指自然无畸形，动作连贯不僵硬；画面稳定不抖动、无闪烁
【真人补充】真实亚洲人皮肤质感，保留毛孔肌理，拒绝过度磨皮，阴影过渡柔和
```

竖屏带货、口播这类可以精简到「画质 + 镜头 + 硬性约束」三项，别把电影机参数全带上——平台会压缩。

## 2. 分镜公式

```text
[0-X 秒]：[运镜] + [景别] + [主体描述] + [连贯动作链条] + [场景环境] + [光影微调]
```

## 3. 运镜词库

| 运镜 | 写法 |
|---|---|
| 固定机位 | 固定机位，带轻微自然呼吸感 |
| 推近 | 缓慢匀速向前推进 |
| 拉远 | 缓慢匀速向后拉开 |
| 横移 | 水平左右横移 |
| 摇摄 | 垂直上下摇摄 |
| 环绕 | 360° 缓慢环绕 |
| 跟拍 | 斯坦尼康跟拍 |
| 甩镜 | 快速甩镜（慎用，容易糊） |

**动作要写慢**：缓慢推进、轻柔转身、逐渐抬头。高速移动、剧烈扭转会崩。

## 4. 景别词库

| 景别 | 覆盖范围 |
|---|---|
| 特写 | 面部 / 手部 |
| 近景 | 胸口以上 |
| 中景 | 腰部以上 |
| 中全景 | 全身 + 近景环境 |
| 远景 | 大环境全景 |

## 5. 光影公式 + 八种常用光

```text
[主光源类型] + [色温] + [投射方向] + [辅光 / 轮廓光] + [聚焦区域] + [明暗对比] + [情绪]
```

| 光型 | 用法 | 一句话写法 |
|---|---|---|
| 伦勃朗光 | 单人情绪 / 悬疑 / 文艺 | 单侧硬光主灯 + 弱辅光，脸颊三角光斑，侧后窄轮廓光，4200K，暗部保留层次 |
| 蝴蝶光 | 甜宠 / 温柔女主 | 正面高位柔光，下方反光板补暗部，5500K，低对比，治愈 |
| 黄昏侧逆光 | 离别 / 黄金时刻 | 夕阳暖调侧逆光，3200K，强发丝轮廓光，正面低亮柔补，冷暖撞色 |
| 三点柔光 | 日常 / 办公室 | 正面柔光 + 侧辅光 + 背部轮廓光，5500K，过渡平缓 |
| 悬疑单硬光 | 密室 / 惊悚 | 顶部单侧硬光，4000K，无辅光，极高明暗对比，大面积暗部 |
| 蓝调夜景 | 都市孤独 | 天空冷蓝 7000K + 街边暖黄，伦勃朗塑形，冷暖对冲 |
| 煤油暖黄 | 夜晚室内离别 | 单盏煤油灯侧方暖光，2600K，低亮辅光提眼窝，伦勃朗三角光斑 |
| 赛博对比 | 霓虹 / 科幻 | 红蓝双色霓虹分侧对冲，混合色温，低亮环境，高反差 |

## 6. 声音公式（带音量）

```text
[持续环境音（dB）] + [定点音效（出现时间 + dB）] + [BGM（曲风 + dB）] + [人声约束]
```

示例：

```text
持续细密雨声（-12dB），第 2 秒纸张撕开声（-6dB），全程低沉钢琴独奏（-18dB）；
人声清晰突出，音效不盖过人声，无多余杂音。
```

常用素材：

- 环境音：雨声、晚风、街道车流、室内底噪、森林风声
- 关键音效：脚步、开门、纸张撕裂、雨滴砸玻璃、金属碰撞、心跳
- BGM：低沉钢琴、舒缓弦乐、氛围电子、无 BGM
