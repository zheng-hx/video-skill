# 声音设计

> 视频模型大多不出台词，声音必须单独交付一份：一段给模型（环境音 + 配乐），一段给 TTS / 真人录音（台词）。
> 不是"加个 BGM"，是**环境底噪 + 动作音 + 呼吸/静默 + 配乐分层**。

## 1. 为什么声音要写这么细

WorkBuddy 两个示例都有完整声音设计。声音设计出来的视频是"能听进去"的，不是"能听见"的。

## 2. 两段模板

```
overall_soundscape: 【全程持续的环境音】 + 【主要动作音列表】 + 【人物呼吸/静默】
non_diegetic_music: 【配乐进入方式】 + 【叠入层次】 + 【音量变化】 + 【收束方式】
```

## 3. 我们项目的声音模板

```
overall_soundscape: 窗外风声/巷口狗叫/安静房间底噪（全程持续）。手指按灭屏幕的清脆碰响、手机屏幕亮起的细微声、坐起来的布料摩擦声、拿起手机的动静（主要动作音）。人物有几段明显的呼吸声与短暂静默（情绪节点）。
non_diegetic_music: 稀疏的钢琴单音以缓慢速度在"刷到姑娘"那段进入，在"梨涡笑"那段音量逐渐增强，在最后定格达到最强后自然收束为一段单音余响。
```

## 4. 各平台对声音的支持

| 平台 | 能直接在提示词里写声音吗 | 方式 |
|---|---|---|
| **混元** | ✅ 原生支持 | 直接写"画面里有微弱的窗外风声""瀑布轰鸣"（混元能生成声音） |
| **可灵** | ✅ 支持 | 在提示词末尾写 overall_soundscape 和 non_diegetic_music |
| **即梦** | ⚠️ 部分支持 | 新版本支持文字渲染字幕，但声音需要后期配或 TTS |
| **Seedance** | ⚠️ 部分支持 | 支持声音参考 `@音频1` |
| **Veo/Sora** | ✅ 原生支持 | 直接写声音描述 |

## 5. 台词语言标签（保证唇形对齐）

WorkBuddy 用 `<d>[Chinese] 台词</d>` 格式保证中文唇形。各平台支持情况：

| 平台 | 语言标签格式 | 什么时候写 |
|---|---|---|
| 即梦 | 直接写中文，模型自动识别 | — |
| 可灵 | `<d>[Chinese] 台词</d>` | ✅ 必须写，保证中文唇形 |
| 混元 | 直接写中文，模型自动识别 | — |
| Seedance | `<d>[zh] 台词</d>` 或直接中文 | 有语言标签更稳 |
| Veo/Sora | 直接写英文或中文 | — |

## 6. 交付形态

- **提示词里**：声音写进每镜的 `声音：` 字段，或统一放提示词末尾（看平台，见 §4）。
- **单独交付**：`===== 台词 / 配音 =====` 一段逐句列出，能直接粘 TTS；没有台词的镜头注明是空镜。
- 台词与配音方式（TTS / 真人 / 数字人、口型怎么办、字幕规范）见 `audio.md`。
