# 分镜与提示词

> 上游是 `story.md` 里的**完整故事和分场**，不是对话记忆，也不是一句话索引。
> 先定风格，再判单条还是多条，最后按骨架填。顺序反了，写完的风格锚就要全部重来。
> 这里的目标只有一个：**让模型拿到能照着生成、而不是靠猜的提示词。**

## 0. 先定风格（会改掉后面所有写法）

风格不是「加个形容词」，是换一套写法。同一个故事，真人写法和漫剧写法完全不同。

| 风格 | 适合 | 风格锚示例 | 关键要求 |
|---|---|---|---|
| **真人实拍感** | 带货 / 口播 / 人设 / 种草 | 暖调、浅景深、手持微晃、低饱和、真实生活感 | 皮肤质感自然，光线可信，口型要对 |
| **AI 漫剧** | 剧情 / 短剧 / 知识 / 情感 | 日系赛璐璐动画风、平涂、清晰描边、高饱和、无真实噪点 | 角色三视图锁死，表情夸张，口型可不对 |
| **3D 动画** | 科普 / 儿童 / 产品演示 | 3D 渲染、柔光、圆润造型、干净背景 | 材质要写清，布光要写清 |
| **插画 / 图文** | 种草 / 知识 / 清单 | 扁平插画、莫兰迪色、纸质感、无阴影 | 平面构图，文字排版留位 |
| **混合** | 口播 + 素材包装 | 真人主体 + 图文包装层 | 层级分明，主体不被包装抢 |

### 混搭不是随便混

`mixed` 要写清三件事：**两个世界各是什么、交界在哪、谁在谁里**。

以「赛博 × 古风」为例：

| 层 | 写什么 |
|---|---|
| 现实侧 | 红黑桌面、机械键盘、RGB 主机、屏幕反光 |
| 虚拟侧 | 金饰纱裙、发冠、古亭、暖灯、烟雾 |
| 交界 | 屏幕玻璃——碎裂、穿透、握手 |

交界那一下是整条片子的高光，必须写细：碎的是哪一块、电光从哪来、手从哪个方向伸出来。

### 怎么选

1. 用户明说了风格 → 按他的。
2. 没说 → 按类型推荐：带货/口播 → 真人；剧情/情感 → 漫剧或真人；科普 → 3D 或图文。
3. 推荐时给两个选项，别只给一个：「这条我建议真人实拍，也可以做成 AI 漫剧，你选哪个？」——**这是会返工的项，必须确认。**

### 漫剧特别说明

AI 漫剧和真人视频是两条工艺线：

- **角色一致性要求更高**：漫剧里脸一漂观众立刻发现。每个主要角色必须有正脸、侧脸、全身三张参考图，身份锚点逐字不变。
- **口型可以不对**：走字幕或配音，不硬追求对口型；要口型就选支持 dialogue 的平台。
- **镜头语言偏动画**：多用推拉、定格、速度线、特效光，少用手持晃动。
- **表情要夸张**：动画的表演幅度比真人大一档，写「眼睛睁大、嘴微张」，不要写「略显惊讶」。
- **分镜节奏偏漫画格**：一个情绪点一个镜头，切得比真人视频碎一点。

## 1. 判单条还是多条

```text
条数 = max( ceil(总时长 ÷ 单次上限), ceil(口播字数 ÷ (单次上限 × 4.5)) )
```

两个判据取大的那个：

- **时长判据**：30 秒的视频、平台单次 15 秒 → 必须 2 段，跟字数无关。
- **字数判据**：口播 70 字、单次 15 秒 → 15×4.5=67.5，装不下 → 2 段。

| 平台单次上限（以实际为准） | 适合字数 |
|---|---|
| 5 秒 | ≤ 20 字 |
| 10 秒 | ≤ 45 字 |
| 15 秒 | ≤ 65 字 |

三条附加规则，任意一条命中就拆：

1. **信息点超过 4 个**——一条装不下这么多画面。
2. **要换场景**——一条内换场景容易穿帮。
3. **有前后对比**——对比必须两个画面。

反过来，同一场景、同一主体、一条连续动作、纯口播，**别拆**。碎切比长镜头更假。

### 镜头数参考（按类型 × 时长）

| 类型 | 5 秒 | 10 秒 | 15 秒 |
|---|---|---|---|
| 漫剧 / 短剧 | 3 镜 | 4–5 镜 | 6–10 镜 |
| 电商产品 | 1–3 镜 | 3–4 镜 | 4–6 镜 |
| TVC / 品牌 | 1–2 镜 | 2–4 镜 | 3–5 镜 |
| 科普 | 2–3 镜 | 3–4 镜 | 4–6 镜 |
| 口播 | 1 镜 | 1–2 镜 | 2–3 镜 |
| 择业 / 行业 | 2–3 镜 | 3–4 镜 | 4–6 镜 |

超了这个数就是碎切，少于这个数就是拖。一镜到底适合：产品 360° 展示、场景横移、人物走位。

## 2. 提示词骨架：14 个字段，一个都别省

每条提示词按这个顺序填。**省字段 = 模型自己补 = 出来不是你想要的。**

「写到什么程度」是**下限**，不是建议——缺一项就算不合格，重写。

| # | 字段 | 写到什么程度 | 坏例子 | 好例子 |
|---|---|---|---|---|
| 1 | 风格锚 | 逐字照抄，全片一致 | 好看一点 | 暖调、浅景深、手持微晃、低饱和、真实生活感 |
| 2 | 主体身份 | 年龄 + 性别 + **≥3 个**外貌特征 | 一个女的 | 28 岁女性，圆脸，内双，齐耳短发，偏白 |
| 3 | 主体造型 | 服装 + **≥1 个**配饰 + 状态 | 穿着衣服 | 米色针织衫，素颜，头发微乱，左手腕细银链 |
| 4 | 表情 | **≥2 个**五官动作 | 表情自然 | 嘴角微扬，眼睛看着镜头，眉毛放松 |
| 5 | 动作 | 起点 + 过程 + 终点，**三段都要** | 涂面霜 | 右手从桌面拿起白色面霜瓶，拇指按泵头，挤出黄豆大小在手背，低头看手背 1 秒 |
| 6 | 场景 | 地点 + 时间 + **≥2 个**陈设 | 卧室 | 清晨卧室，前景梳妆台边缘虚化，中景人物坐姿，背景窗帘和床，台面有玻璃杯和梳子 |
| 7 | 光线 | 光源 + 方向 + 强度 + 色温 | 自然光 | 左侧窗户进来的阴天自然光，光比柔和，左脸亮右脸暗，色温偏冷 |
| 8 | 镜头 | 景别 + 角度 + 运镜 + 视角 + 焦段感 | 电影感 | 第一人称视角，中景，眼平高度，缓慢推近，等效 50mm，浅景深 |
| 9 | 构图 | 主体位置 + 留白 + 前景，**三样都要** | 居中 | 人物居中偏左，右侧留白给窗外，前景桌面边缘占下 1/5 |
| 10 | 质感 | **≥3 项**：材质 / 颗粒 / 锐度 / 调色 | 高清 | 皮肤有细微毛孔，胶片颗粒轻，锐度中等，低饱和偏青 |
| 11 | 约束 | 防崩：结构、五官、动作、稳定 | 别崩 | 人物结构正常，面部清晰不变形，五官稳定，比例自然，动作不僵硬，画面不抖动 |
| 12 | 负向词 | **≥5 个**，且必须含二维码 / logo / 水印 | 不要奇怪的东西 | 水印、字幕、文字、畸形手、多余人物、面部漂移、塑料感 |
| 13 | 参数 | 时长 + 画幅 | 短视频 | 5 秒，9:16 竖屏 |
| 14 | 声音 | **台词原文完整写进去** + 谁来说 + 环境音 + BGM | 她说了一句 | 画外女声说「熬夜脸发黄？」，语气疲惫；环境音清晨鸟叫；BGM 轻钢琴 -18dB |

**判据**：写完遮住提示词，只看它能不能在脑子里想象出这一帧。想象不出来，就是不够细。

### 分镜不是复制粘贴：首镜完整，后续续接

最常见的错：每镜都把主体、场景、风格重写一遍。结果：

- 每镜开头一模一样，看起来像同一帧
- 模型每次从零生成，动作接不上
- 出来是 5 条独立视频，不是 1 条分镜

**正确写法**：

| 镜 | 开头 |
|---|---|
| s1（首镜） | 完整写：风格锚 + 主体 + 造型 + 表情 + 动作 + 场景 + 光线 + 镜头 + 构图 + 质感 |
| s2 之后 | 「**接上一镜**：<上一镜结束状态>。<本镜动作>。<本镜结束状态>」；主体只写「同一人物」，不再重述外貌 |

例：

```text
s1：暖调、浅景深、手持微晃、低饱和、真实生活感。28 岁女性，圆脸，内双，齐耳短发，偏白；米色针织衫……坐在梳妆台前，低头看手机。
s2：接上一镜：她抬头看向镜子，右手空着停在桌面。同一人物，右手拿起面霜瓶，拇指按泵头，挤在手背。结尾右手停在瓶口。
s3：接上一镜：她低头看着手背，右手在瓶口。同一人物，抬头看向镜子，嘴角扬起。
```

这样每镜开头不同，动作是接的。

**为什么后续不再重述外貌**：重述就会写错一个字，每镜轻微变脸。主体靠角色 id + 参考图锁，不靠文字复述。

### 声音是必填项，不是装饰

**台词必须写进画面提示词，不只是 line 字段**：

| 模型支持声音吗 | 提示词里怎么写 | 结果 |
|---|---|---|
| 支持（Veo 等） | 写对白：「正在说话，说：『熬夜脸发黄？』」 | 一次出，声画同步 |
| 不支持 | 也要写「嘴唇微动，正在说话」 | 人至少张嘴，声音后配 |
| 只写了 line、画面没写说话 | — | 人站着嘴不动，后配音也对不上，**整条废** |

浪费的不是一次生成，是一次 token + 一次选题机会。

**视频生成模型大多不出台词**——文生视频出来是哑的。所以：

- 台词必须写进分镜（每镜 `line` 字段），**同时把原文放进 prompt 的「声音」段**——门禁会查：`line` 不在 prompt 里直接 FAIL。
- 画面提示词里写声音，只在平台支持音频时有用（Veo 等）；不支持的，声音靠后配。
- 交付时**台词单独列一份**，给 TTS 或真人录音用，别指望视频里自带。
- 没有台词的镜头标 `silent: true`，别空着。

详见 `references/audio.md`。

### 三个写作规矩

- **一镜一个主动作**，最多带一个微动作（眨眼、吞咽、抬手）。
- **先写视线，再写手**：不然手会抢脸。
- **一条提示词最多两个主动作**。超过两个，模型大概率只出前一个；要更多变化就拆镜。单条模式可以有「起态 → 变化 → 落态」的弧线，但**变化点只算一个动作**。

### 一体式写法（吃长自然语言的平台用）

有些平台（Veo / Sora / 长描述型）吃一段连贯文字，比分字段更自然。这时把 12 个字段按顺序串成一段，信息一个不丢：

```text
视角 → 风格锚 → 场景 → 主体 → 环境 → 动作弧线 → 质感 → 氛围
```

示例：

> 超写实第一人称视角，玩家在红黑电竞桌面操作设备，机械键盘、RGB 灯效主机营造赛博科技氛围；电脑屏幕中呈现高细节古风女角色，身着华丽金饰点缀的古风纱裙，头戴精致发冠，身处古亭、暖灯、烟雾缭绕的游戏场景中；角色转身与现实玩家的手互动，随即屏幕玻璃碎裂（带电光特效），角色冲破屏幕与玩家手紧握，从虚拟世界破壁进入现实。画面融合电竞科技感（红蓝光效、高端硬件）与古风玄幻质感，电影级 CG 特效，细节写实到角色服饰纹理、屏幕碎裂的每一片玻璃，营造沉浸式次元突破的奇幻感。

这段拆开看，12 个字段一个不少：

| 字段 | 在这段里的位置 |
|---|---|
| 视角 | 第一人称视角 |
| 风格锚 | 超写实 + 电影级 CG 特效 |
| 场景 | 红黑电竞桌面 |
| 主体 | 古风女角色（金饰、纱裙、发冠） |
| 环境 | 古亭、暖灯、烟雾 |
| 动作弧线 | 转身 → 互动 → 玻璃碎裂 → 破屏握手 |
| 质感 | 服饰纹理、每片碎玻璃、RGB 光效 |
| 氛围 | 赛博科技 × 古风玄幻，次元突破 |

**坑也要说清**：这段塞了四个动作（转身、互动、破屏、握手），实际生成时模型很可能只完成前两个。想完整出现，得拆成两条——一条到「玻璃碎裂」，一条到「伸手相握」。**混搭风格 + 多动作，是最容易只出半段的组合。**

### 时间轴格式（单条 10–15 秒、一条里有多个事件时用）

有些平台支持逐秒控制（Seedance / 可灵等）。把一条视频按时间切片，每段写「镜头运动 + 画面 + 情绪」：

```text
[风格]，[时长]秒，[画幅]，[整体氛围]

[0-3秒]：俯拍全景，镜头缓慢下降，风雪中的草料场
[3-6秒]：中景推近，人物抬头，眼神望向远方
[6-9秒]：面部特写，呼出白气消散
[9-12秒]：环绕镜头，人物独立雪中
[12-15秒]：拉远，背影消失在水墨晕染里

【声音】配乐 + 音效 + 对白
【参考】@图片1 首帧，@图片2 尾帧，@图片3 角色
```

规则：

- 每段只放一个动作；段与段之间状态要对上（就是 handoff 那套）。
- 总时长必须等于平台单次上限，装不下就拆。
- `@图片` / `@视频` 这种参考语法，只在平台支持时写，别硬套。

### 平台语法差异

同一段内容，不同平台写法不一样，别交叉抄：

| 平台 | 结构 | 单次时长 | 特殊写法 |
|---|---|---|---|
| 即梦 | 镜头类型 + 场景 + 人物动作 + 情绪 + 风格 | 5–15 秒 | 中文优先，支持 `@图片N` |
| 可灵 | 场景 + 角色动作 + 氛围 + 光色 + 运镜 | 5–10 秒 | 中英文都可 |
| Seedance | 时间轴分段 | ≤15 秒 | `@图片` / `@视频` / `@音频` 参考 |
| Veo / Sora | 一段连贯英文长句 | ≤8 秒 | 自然语言，少堆参数 |
| Midjourney | 关键词 + 参数 | 静图 | `--ar` / `--v` 结尾 |

> 时长和参数以官方文档为准，这张表只用来提醒「别串台」。

## 2.8 时间轴：每镜从第几秒到第几秒

分镜表只写「时长」不够——剪辑、配音、字幕全都要按时间对位。

```text
| 镜号 | 时间   | 时长 | 画面 |
| s1   | 0–4s   | 4s   |
| s2   | 4–10s  | 6s   |
| s3   | 10–15s | 5s   |
```

`storyboard.json` 里对应 `start` / `end`，门禁查三条：

1. 第 N 镜的 `start` = 第 N−1 镜的 `end`（不能有空档，也不能重叠）；
2. `end − start` = `duration`；
3. 最后一镜的 `end` = `meta.duration`。

提示词开头标一段「【第 N 段 · 整条 X–Y 秒】」，用户拿去生成时知道这段排第几、接哪里。

## 2.9 时长怎么算

| 东西 | 占不占生成时长 |
|---|---|
| 镜头里的戏 | 占 |
| `ending` 落版 / 定格 | **不占**，叠在最后一两秒上 |

所以 `shots` 的 duration 加起来要**等于** `meta.duration`，别把落版单独扣出去。

`meta.max_shot_duration` 可以写平台单次上限（默认 15 秒）；任何一镜超过，门禁直接拦——超了生成不了，得拆。

## 3. 及格线示例（不是范本，看密度用）

> 这两段只是让你知道「及格」长什么样——字段齐、有镜头、有光线、有质感。别照抄，抄出来都长一个样。

### 真人实拍感

```text
暖调、浅景深、手持微晃、低饱和、真实生活感。
28 岁女性，圆脸，内双，齐耳短发，偏白；米色针织衫，素颜，头发微乱。
表情：嘴角微扬，眼睛看向镜子。
动作：右手从桌面拿起白色面霜瓶，拇指按泵头，挤出黄豆大小在手背，低头看手背一秒。
场景：清晨卧室，前景梳妆台边缘虚化，中景人物坐姿，背景窗帘和床，台面有玻璃杯。
光线：左侧窗户进来的阴天自然光，光比柔和，左脸亮右脸暗，色温偏冷。
镜头：中景，眼平高度，缓慢推近，等效 50mm，浅景深。
构图：人物居中偏左，右侧留白给床。
质感：皮肤有细微毛孔，胶片颗粒轻，锐度中等，低饱和偏青。
负向：水印、字幕、文字、畸形手、多余人物、面部漂移、塑料感。
参数：5 秒，9:16 竖屏。
```

### AI 漫剧

```text
日系赛璐璐动画风、平涂、清晰描边、高饱和、无真实噪点。
17 岁少女，黑色长直发，齐刘海，红色发绳；白衬衫配藏青百褶裙，领口别校牌。
表情：眼睛睁大，嘴微张，眉毛上挑。
动作：从座位站起，双手撑住桌面，身体前倾看向窗外。
场景：教室，前排课桌虚化，中景人物半身，窗外樱花树，黑板在背景偏右。
光线：逆光，窗外阳光打在头发边缘形成高光，室内偏暗，色温偏暖。
镜头：中景，略低角度，缓慢推近，等效 35mm。
构图：人物居中偏左，右侧留白给窗户。
质感：赛璐璐平涂，阴影边缘清晰，无景深模糊（动画感），高饱和。
负向：真实照片感、真实皮肤纹理、3D 渲染、水印、字幕、多余人物。
参数：4 秒，9:16 竖屏。
```

对比着看：真人要写**质感**和**光线方向**，漫剧要写**描边/平涂/饱和度**；漫剧的镜头更固定、更敢用仰拍和大特写。

## 4. 详细度自检

### 机器查（`check-storyboard.py`）

- 提示词长度 ≥ 60 字
- 含风格锚
- 含镜头词（景别或运镜）
- 含光线词
- 含负向词

### 人查

- [ ] 遮住提示词，只看它能不能想象出这一帧
- [ ] 动作有起点和终点，不是一句动词
- [ ] 光线有方向，不是「自然光」三个字
- [ ] 镜头有景别和运镜，不是「电影感」
- [ ] 风格锚在每镜逐字一致，没有换成同义词
