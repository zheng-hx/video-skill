# 提示词反面清单

> **这份文件是硬标准，正面示例只是标尺。**
> 一次生成失败，多半不是「没写好」，是踩了下面某一条。先对照这份排，排完再谈画面好不好看。

## 1. 模糊词（出现就重写）

```
好看 / 电影感 / 大片感 / 高级感 / 氛围感 / 有质感 / 震撼 / 唯美 / 高级 / 绝了
```

**为什么坏**：这些词是评价，不是描述。模型不知道「电影感」是浅景深、是冷调、还是广角。

**改法**：把评价换成可拍参数——「电影感」→「浅景深、冷调、16:9、等效 35mm」。

## 2. 动作问题

| 症状 | 为什么坏 | 改法 |
|---|---|---|
| 一条塞 >2 个主动作 | 模型只出前一个，后面的全丢 | 拆镜，或砍到一个 |
| 只写一个动词（「涂面霜」「走」「看」） | 没有起点终点，模型自由发挥 | 写「从 A 到 B」 |
| 动作和机位冲突（固定机位写一整套动作） | 固定机位拍不出转身 | 换运镜或拆镜 |
| 动作太快（高速移动、剧烈扭转、夸张甩动） | 越快越容易崩，模型追不上 | 写慢：缓慢推近、轻柔转身、逐渐抬头 |
| 一条里视角乱跳（第一人称混第三人称） | 观众晕，模型也跟着晕 | 全片一个视角 |

## 3. 光线问题

- 只写「自然光」三个字 → 没有方向、没有冷暖，出来是平的。
- 没写光从哪来 → 模型默认均匀打光，像证件照。
- 写了「亮」但没写谁亮 → 不知道是脸亮还是背景亮。

**改法**：光从哪来、打在谁身上、光比软硬、色温暖冷，四样至少写三样。

## 4. 镜头问题

- 没有景别（特写/中景/全景）。
- 没有运镜，或一条里塞了「推拉摇移」四个。
- 写了「电影感镜头」这种不算镜头的词。
- 视角没写：第一人称还是第三人称，主观还是客观。

**改法**：景别 + 角度 + 运镜 + 视角，四件套写全，运镜最多一个。

## 5. 风格问题

- 风格锚换个同义词（「暖调」写成「暖色调」）→ 每镜色调都会飘。
- 混搭没写交界（现实侧、虚拟侧、交界在哪）→ 出来是两张皮。
- 漫剧里写「真实皮肤纹理」「毛孔」→ 风格打架。
- 真人里写「赛璐璐描边」→ 同上。

## 6. 主体问题

- 每镜重写一遍外貌描述 → 每镜都轻微变脸。
- 服装和长相混在一起写 → 换套衣服就换张脸。
- 不引用角色 id。

**改法**：长相一次写死，之后只引用 id；服装单独写。

## 7. 平台问题

- 把即梦的 `@图片1` 语法塞给 Sora。
- 把 Veo 的 JSON 提示词塞给剪映。
- 负向词里塞正向要求（负向里写「要清晰」）。

**改法**：先确认目标平台，再挑写法；不确定就给通用版并标明待适配。

## 8. 衔接问题

- 写「保持连续」「同上」「延续上一镜」。
- 尾帧和下一镜首帧只对齐了「人物」，没对齐站位、朝向、持物、光向。
- 一条里人物左手变右手，门开了又关。

**改法**：写成可见事实，见 `continuity-and-handoff.md`。

## 9. 交付问题

- 宣称「已生成成片」，实际只给了提示词。
- 提示词太长塞不下，悄悄截断。
- 负向词一个没有。

## 10. 语言问题

| 症状 | 为什么坏 | 改法 |
|---|---|---|
| 写真实姓名（「林冲」「张三」） | 模型不认识这个名字，只能瞎猜 | 用外貌和身份描述代替 |
| 写叙事语言（「他突然意识到……」） | 这是小说写法，不是画面描述 | 换成看得见的动作和表情 |
| 写抽象情绪（「她很悲伤」） | 模型不知道悲伤长什么样 | 写「眼眶发红，嘴唇抿紧，肩膀往下塌」 |
| 写比喻（「美得像一幅画」） | 画是什么画？ | 直接写构图和色调 |

## 怎么用这份清单

1. **写完先排一遍**：从上往下，命中任意一条就改，改完再往下。
2. **机器能查的交给脚本**：模糊词、空话、字段缺失，`check-storyboard.py` 会报。
3. **机器查不了的靠这一条**：把提示词给别人看，问「你能想象出这一帧吗」。想象不出来，就是没写细。

> 正面示例存在的唯一理由：让你知道「及格」长什么样，别写太瘦。它不是范本，不用抄。
