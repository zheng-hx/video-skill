# 傻瓜操作卡

> 给「只想用」的人。不解释原理，不出现术语，只写他要做的动作。
> 一次只做一件事，做完发回来。

## 模板

```markdown
# 做这条视频，你只要三步

## 1. 打开【即梦】App
（手机上有的就在应用商店搜「即梦」，没有就告诉我，我换一个。）

## 2. 把下面这段复制进去，点「生成」

```text
【第一段完整提示词】
```

（一共 N 段，这是一段。生成好先发我，我看看对不对，再给你下一段。）

> 提示词**必须给全**，不能只写「见附件」或「按上面那段」——用户看不懂上下文，他只会复制这一块。

## 3. 生成好，把视频发回来
我帮你把几段拼成一条，再检查一遍。
```

## 规则

1. **只写他要做的事**，不写「为什么」。
2. **一次一步**，最多三步。超过三步就拆成两轮。
3. **告诉他去哪里点**，不告诉他参数是什么。
4. **生成完发回来**——这句话必须写，否则他不知道下一步。
5. 遇到他不会的东西（比如「没有这个 App」），给替代方案，不让他去搜教程。

## 三种情况

| 情况 | 给什么 |
|---|---|
| 他自己能生成（有手机、有 App） | 操作卡：打开哪个 App、粘哪段、发回来什么 |
| 他连 App 都没有 | 先问「手机上有豆包 / 即梦吗？」有就给一段喊话（见 `assets/ask-ai.md`）；真没有才给「拍摄清单」 |
| 你（宿主）能直接生成 | 不给他卡，直接给他视频，说「这条好了，看看行不行」 |

## 不要说

- 「提示词」「分镜」「分辨率」「画幅」「模型」
- 「你可以试着自己调一下」
- 「按文档操作」
- 「如果报错就把错误发给我」
