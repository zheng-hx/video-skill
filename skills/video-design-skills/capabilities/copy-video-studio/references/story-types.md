# 招人故事库

> 用户要招人，但直接写招聘没人看。
> 用别人的故事把人吸引过来，最后一句才落到招人。
> 故事可以换着讲，目的只有一个：**让人来试**。

## 1. 九种故事

| 类型 | 主角 | 冲突 | 转折 | 招人落点 |
|---|---|---|---|---|
| **转行型** | 客服 / 导购 / 文员 | 干着没劲、钱少、看不到头 | 刷到别人的直播，试了一次 | 我也在招，你来试试 |
| **跳槽型** | 别家的主播 | 没流量、分成低、没人带 | 换了团队，有人手把手带 | 我们还在补人 |
| **新手型** | 完全没经验 | 第一次开播翻车，话都说不利索 | 被带着练，慢慢起来 | 没经验也有人带 |
| **宝妈型** | 带孩子的 | 想顾家又想挣钱 | 时间能自己排 | 时间能按你的来 |
| **被裁型** | 刚被裁 / 店关了 | 找工作四处碰壁 | 试了这行 | 我们缺人 |
| **副业型** | 白天上班 | 工资不够花 | 晚上播两小时 | 可以先兼职试 |
| **学历型** | 大专 / 中专 | 好工作都看学历 | 这行看能不能坚持 | 不看背景 |
| **对比型** | 同批进来的一群人 | 有人留下有人走 | 留下的做对了什么 | 想清楚再来 |
| **幕后型** | 运营 / 团队 | 怎么把一个人从零捧起来 | 团队做了什么 | 我们这样带人 |

## 2. 结尾不是「招人」，是给一个钩子

直接说「我们在招人，来应聘」——那是硬伤。读者没有理由现在就联系你。

要给一个**让人好奇、门槛又低**的动作：

| 钩子类型 | 话术 | 为什么有效 |
|---|---|---|
| **资料钩子** | 私信我，发你一份《新人第一个月怎么过》 | 白拿东西，不亏 |
| **群钩子** | 评论区打「想听」，拉你进群，群里发真实数据 | 群 = 有更多信息 |
| **剧透钩子** | 关注我，下条讲「主播一天到底在干嘛」 | 想知道下文 |
| **收入钩子** | 想知道一个月到底能拿多少，评论区问 | 直接利益 |
| **判断钩子** | 不确定自己适不适合？私信我，三分钟帮你看 | 降低门槛 |

**原则**：先让人「来了解」，再谈「来应聘」。别一步到位。

**不能做的**：结尾甩一句「我们招人，简历发我」——那是招聘启事，不是故事结尾。

## 3. 怎么用

- **一条只讲一个故事**，别混。混了就成四不像。
- **换着讲**：同一账号别连着发同一种，隔几条换一个类型。
- **结尾给钩子**：入群 / 领资料 / 看下条 / 问收入，一个动作就够，别堆三个。
- **困难必须写**。只讲好的，评论区第一条就是「骗人的」。
- **故事里的人要具体**：有名字、有过去的工作、有一个具体动作（手抖、把手机扣桌上）。

## 4. 跳槽型特别说明

「看见别家主播后跳槽」这种最容易踩雷，注意三条：

- **不点名别家**，不写公司名、不写平台名。
- **不拉踩**：「我们比他们好」这种话一句都不要。
- **问题用普遍现象写**：「没流量」「没人教」「播三个月还是十几个人」——这是行业常见情况，不是某家的错。

## 5. 对比型怎么讲才不伤人

「有人留下有人走」容易变成「走了就是不行」。改法：

- 讲**留下的人做对了什么**，不讲走的人哪里差。
- 落点放在「你也可以判断自己适不适合」，不是「你得坚持」。

## 6. 故事从哪来

- 用户自己发的、效果好的，进知识库（`library.py`）。
- 真实案例优先。编的可以，结果不能编。
- 每个故事存一条：主角画像 / 冲突 / 转折 / 结果 / 好用的话。

- [ ] 没点名别家、没拉踩
- [ ] 结果没编具体数字
