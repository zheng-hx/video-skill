# 合规红线与标红格式

> 三个环节共用一份。招主播的 JD 承诺、文案的卖点、视频的配音字幕，都受这套约束。
> 本文给的是**通用硬规则**，不替代法务；涉及具体品类资质时，让用户确认。

## 0. 标红格式（必须统一，否则不能验收）

输出里出现合规问题时，一律写成这行格式，紧跟在原句后面：

```
【合规·禁用】原句 → 改写建议
【合规·风险】原句 → 为什么有风险
【合规·待确认】原句 → 需要用户确认的资质/依据
```

- **禁用**：法律明文不允许，必须改。
- **风险**：平台大概率限流/下架，建议改。
- **待确认**：不确定，要用户提供资质或依据才能定。

自检清单里勾完，交付时在末尾汇总一行：「合规问题 N 处，已标红。」

## 1. 绝对化用语（《广告法》第九条）

以下词不得出现（同义变体也算）：

| 类别 | 禁用词 |
|---|---|
| 等级类 | 国家级、世界级、最高级、最佳、最好、最优、最强、最大、顶级、极品、极致 |
| 排名类 | 第一、NO.1、首个、唯一、独家、王牌、冠军、销量第一 |
| 时间类 | 史无前例、绝无仅有、万能、永久、永不 |
| 效果类 | 100%、百分百、彻底、根治、完全、零风险 |

> 改写方向：把绝对表述换成**可核实的具体事实**。
> 「全网最好用的」→「近 30 天复购率 42%」；「第一品牌」→「2025 年天猫该类目销量前 10」。

## 2. 分品类功效宣称红线

| 品类 | 不能说 | 可以说 |
|---|---|---|
| 普通食品 | 减肥、降脂、降糖、增强免疫力、治疗 | 口感、配料、食用场景、营养成分含量（须有检测） |
| 保健食品 | 治疗、治愈、替代药物、无副作用 | 已备案的保健功能（须有批准文号） |
| 化妆品 | 药妆、医学护肤、治疗痤疮、修复受损（需谨慎） | 保湿、清洁、已备案的功效（美白/防晒属特殊化妆品，须有备案） |
| 医疗器械 | 治愈率、根治、无风险 | 注册证载明的适用范围 |
| 教育 | 保过、包就业、100% 通过 | 课时、师资资质、往期学员数据 |

> 没有对应资质就**不要写功效**。宁可写场景和体验，不碰功效。

## 3. 金融 / 收益类

- 禁用：保本、保收益、无风险、稳赚不赔、年化 XX%（无资质）、躺赚。
- 「投资有风险」提示是底线，不是免责符。

## 4. 平台导流规则（差异大，按平台判）

| 平台 | 敏感行为 | 处理 |
|---|---|---|
| 抖音 | 口播/字幕出现微信号、二维码、手机号、外部链接 | 一律删除；改为「主页」「评论区置顶」等平台内承接 |
| 小红书 | 明显导流微信、公众号、加 V | 会被限流；改为平台内私信或店铺 |
| 视频号 | 导流相对宽松，但广告内容仍受限 | 保留但标注风险 |
| 快手 | 类似抖音，站外导流管控严 | 同上 |

> 合规的承接方式只有一种：**留在平台内**。要私域就明说「这条内容不适合放私域引导」，别硬塞。

## 5. 招主播相关（用工与承诺）

> **前置提醒**：抖音 / 快手 / 小红书对「招聘」「薪资」「保底」「月入」类内容敏感，直接写招聘容易被限流或下架。
> 默认走「择业」文案（见 `copywriting.md` §1.1.1），把「招人」藏进「帮你看行业」里。
> 硬招募只用于私信、朋友圈、招聘平台。


- 薪资、分成、保底必须**真实可兑现**；「月入十万」这类必须给条件（如「头部主播实际区间」）。
- 不得承诺「零门槛」「包学会」。
- 涉及肖像使用、竞业、试用期的，按公司制度与当地法规，JD 里能写清就写清。
- 未成年人、学生兼职需注意用工合规。

## 5.5 平台限流（不是违规，但会被压流量）

有些内容不违法、也不至于下架，但平台不推——**发得出去，没人看见**。这比违规更难发现。

| 类别 | 典型表述 | 为什么压 | 软性写法 |
|---|---|---|---|
| 招工 / 用工 | 招主播、底薪、保底、月入、包吃住、薪资面议 | 招聘类在短视频平台属低质商业信息 | 改「择业 / 行业观察」，见 `copywriting.md` §1.1.1 |
| 医疗 / 功效 | 根治、祛斑、美白、药妆、医学护肤 | 无资质一律压 | 改体验描述：「用了一阵，看着亮了些」 |
| 金融 / 收益 | 稳赚、保本、日入过万、财富自由 | 高风险内容 | 换成「怎么算账」，不做承诺 |
| 站外导流 | 加微信、留电话、二维码、站外链接 | 导流 | 改「评论区聊」「主页看看」 |
| 诱导互动 | 点关注抽奖、不转不是中国人、点关注领红包 | 诱导行为 | 换成内容本身的价值 |
| 擦边 / 低俗 | 性暗示、过度暴露 | 低俗内容 | 改场景和表达 |
| 假人设 / 假数据 | 编造身份、伪造销量 | 虚假宣传 | 用真实可核的细节 |
| 敏感话题 | 地域对立、性别对立、卖惨 | 争议内容 | 换具体场景，不贴标签 |

**判断顺序**：先看是不是违规（会下架），再看是不是限流（不推流）。两个都会要命，但处理方式不同——违规要删，限流要换说法。

**限流词和违规词的区别**：

- 违规词：「最好」「100%」——法律不让写。
- 限流词：「招主播」「底薪 6000」——法律没禁止，但平台不推。

## 6. 交付前自检

- [ ] 绝对化用语已全表排查（不是只看几个常见词）
- [ ] 功效宣称有资质依据，无资质则已删除
- [ ] 金融/收益承诺无保本保收益表述
- [ ] 平台导流已按对应平台规则处理
- [ ] 所有合规问题已按第 0 节格式标红
- [ ] 交付末尾有「合规问题 N 处」汇总
