# 秀场 / 娱乐直播

> 秀场直播卖的不是货，是**陪伴感、参与感、情绪价值**。
> 但它也是所有直播形态里监管最严的一类。写话术前先把第 5 节看完，那里是能让你号没了的部分。

## 0. 先说一句"圈钱"

行业里没有"圈钱"这个正经说法，叫**营收 / 打赏转化**。

两者的区别很实在：

| | 圈钱思路 | 经营思路 |
|---|---|---|
| 目标 | 一次榨干 | 长期复购 |
| 手段 | 情绪施压、攀比、剧本 | 内容、陪伴、参与感 |
| 结果 | 榜一大哥走人，账号被罚 | 有一批稳定回来看你的人 |

平台现在打击的，恰好是左边那套。抖音今年处置了 34 万个直播间、10.4 万个账号，其中被回收直播权限的，大多是"恶俗 PK""虚假悲情人设""诱导未成年人"这三类。**这套打法已经不是灰色，是明令禁止。**

所以下面写的都是右边那套。

## 1. 底层逻辑

```
留人 → 互动 → 情绪价值 → 打赏（自然结果）
```

不是反过来的。先想"怎么让人留下来"，再想"怎么让人花钱"。

## 2. 一场直播的话术骨架

| 阶段 | 时长 | 目标 | 做什么 |
|---|---|---|---|
| 开场暖场 | 0–3 分钟 | 留住刚进来的人 | 自我介绍 + 今天看点 + 一个互动钩子 |
| 互动升温 | 3–15 分钟 | 让观众开口 | 提问、选择题、点歌、连麦 |
| 内容高潮 | 15–60 分钟 | 给情绪价值 | 才艺、PK、团播玩法 |
| 收尾 | 最后 5 分钟 | 为下一场铺垫 | 预告 + 关注引导 |

## 3. 具体话术

### 3.1 开场 20 秒（决定 80% 的留人）

三句话结构：**拦一下 → 给个理由 → 埋个钩子**

- 「刚进来的宝子别划走，今天有个事得先说」
- 「今天不卖东西，就陪你们聊会儿，想听歌的等会儿点」
- 「人再多点我唱那首，现在人还不够啊」

> 别一上来就自我介绍三分钟，没人听。

### 3.2 欢迎新人

**念名字 + 给一个动作 + 一个理由留下**

- 「欢迎 XX，第一次来吧？点个关注，明天这个点我还在」
- 「XX 这个名字好记，我记住你了啊」

> 不要只念名字，念完就忘。给一个具体的小动作，人家才有反应。

### 3.3 互动提问（把观众从看变成参与）

| 类型 | 例子 | 为什么有用 |
|---|---|---|
| 二选一 | 「老歌还是新歌？打 1 或 2」 | 门槛低，好打字 |
| 状态题 | 「今天上班累不累？累的打累」 | 有共鸣 |
| 认领题 | 「有没有跟我一样夜猫子的？」 | 找同类 |
| 点歌 | 「想听什么打在公屏上」 | 直接参与 |
| 连麦 | 「连麦聊五分钟，谁先来」 | 高参与，也涨时长 |

### 3.4 礼物感谢（分级，但别攀比）

公式：**具体描述 + 专属称呼 + 一个动作或延展**

| 级别 | 说法 |
|---|---|
| 小礼物 | 「谢谢 XX 的小心心，今天第一颗，我记着了」 |
| 中等礼物 | 「XX 这个礼物有点东西，我给你唱一段」 |
| 大礼物 | 「XX，这个我真没想到，谢谢你，今天我多播半小时」 |

**不要说**：
- 「谢谢」（太干）
- 「XX 都送了，其他人呢」（施压，违规）
- 「再刷一个我就 XXX」（交换承诺，违规）
- 比较礼物金额（违规）

### 3.5 PK / 团播拉票

- 「现在差 XX，想帮我的扣 1，我看看有多少人」
- 「输了我就唱歌，赢了你们点」
- 团播：「想看谁的节目，礼物归谁，你们定」

**PK 惩罚只能是才艺类**（唱歌、跳舞、讲段子）。恶俗惩罚、侮辱性惩罚是平台重罚项，4.3 万个账号就是栽在这。

### 3.6 下播

- 「明天同一时间，还是这个点，别忘了我」
- 「今天没听够的，明天开场那首补上」

## 4. 视频（直播之外的内容）

秀场主播的短视频不是带货，是三件事：

| 类型 | 拍什么 | 目的 |
|---|---|---|
| 直播切片 | 高光 15–30 秒，最好带一个情绪爆点 | 给直播间导流 |
| 预告视频 | 明天播什么、有什么特别环节 | 提醒老粉 |
| 人设视频 | 日常生活、性格反差、态度表达 | 让人记住你这个人 |

> 切片的核心是「让人想进直播间看完整的」，不是把整段搬过来。

## 5. 红线（这一节最重要）

### 5.1 官方要求（中央网信办《关于加强网络直播打赏规范管理的通知》，2026-04）

平台侧已经强制执行的几条，主播侧要知道的：

- **不得以打赏额排名**、不得公开消费统计
- **不得打赏返现、自我打赏**——刷礼物返钱、自己给自己刷，都是明确禁止
- **不得为打赏用户设置特殊保护权限**
- 未成年人：8 岁以下不得打赏；8–16 岁需监护人同意；16 岁以上需监护人同意或核验收入
- 账号有违规记录，处置期满 3 个月后才能开通打赏营利权限
- 被禁言会同步暂停打赏权限，时长是禁言期的 2–3 倍

### 5.2 平台在打什么（抖音 2026-06 公告）

| 类型 | 处罚量级 | 具体表现 |
|---|---|---|
| 诱导未成年人消费 | 143 个账号回收直播权限 | 低幼画风 + 「谁给礼物谁就是最勇敢的」 |
| 恶俗 PK 惩罚 | 4.3 万个账号 | 侮辱性 PK、低俗惩罚 |
| 虚假悲情人设 | 903 个账号 | 编造父母离世、单亲妈妈博同情 |

识别方式：**直播画面 + 语音话术 + 礼物消费，多维度一起看**。别以为说小声就听不见。

### 5.3 绝对不做

- 以礼物为条件的交换承诺（「刷火箭就……」）
- 攀比施压（「XX 都刷了你怎么不刷」）
- 虚假人设、剧本化卖惨
- 恶俗 / 侮辱性 PK 惩罚
- 诱导未成年人打赏
- 打赏返现、自我打赏

### 5.4 可以做，但要克制

- 感谢话术要有，但别诱导
- 拉票可以，但别施压
- 剧本可以有，但别演「悲情」
