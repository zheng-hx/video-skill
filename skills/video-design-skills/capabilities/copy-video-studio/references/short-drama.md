# 短剧模式（多集）

> **默认不做短剧。** 用户明确说「做短剧 / 连续剧 / 几集」才切到这里。
> 单条视频走 `scene-script.md`，两套别混。

## 1. 什么时候用

- 用户说「做一部短剧」「拍三集」「连续剧」「有下集」
- 用户要「追更」「钩子」「下一集」

没说这些，就默认单条。

## 2. 跟单条的区别

| | 单条剧情视频 | 短剧 |
|---|---|---|
| 体量 | 15–60 秒一条 | 多集，每集 60–120 秒 |
| 主线 | 没有，一条讲完 | 有，贯穿全剧 |
| 人物 | 每条可以换人 | 贯穿，每集都在 |
| 结尾 | 收住 | 留钩子，勾下集 |
| 前情 | 不需要 | 需要，观众要记得上一集 |

## 3. 流程

1. **定盘子**：题材、集数、调性、结局类型——一次问清楚，别边写边改。
2. **全剧骨架**：主线一句话 + 三幕（入局 / 纠缠 / 决战）+ 每幕几集。
3. **分集目录**：每集一行：集数、一句话梗概、钩子类型。
4. **单集剧本**：用 `scene-script.md` 的格式写，一场一场来。
5. **每集结尾留钩子**。

## 4. 钩子类型

| 类型 | 例子 |
|---|---|
| 悬念钩 | 她打开那个箱子，里面是—— |
| 反转钩 | 镜头一转，刚才那个人站在她身后 |
| 情绪钩 | 她笑了一下，眼泪掉下来 |
| 信息钩 | 手机弹出一条：我知道你是谁 |

一集只留一个，别堆。

## 5. 人物贯穿

- 每个主要角色一张卡：身份锚点、造型、想要什么、怕什么。
- 跨集不许改。改了就是另一个人。
- 台词口气也要一致：她说话短还是长，直还是绕，每集一样。

## 6. 分集目录格式

```markdown
| 集 | 梗概 | 钩子 |
|---|---|---|
| 1 | 她被裁，假装上班 | 悬念：公司群里那条消息她没点开 |
| 2 | 她去面试，被问学历 | 反转：面试官是她前同事 |
```

## 7. 自检

- [ ] 有主线，不是一集一个故事
- [ ] 每集结尾有钩子，且只有一个
- [ ] 人物卡跨集一致（长相、服装、口气）
- [ ] 单集剧本用 scene-script 格式
- [ ] 分集目录能看出节奏，不是流水账
