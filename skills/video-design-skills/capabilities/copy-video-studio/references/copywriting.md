# 写文案工作流 (Copywriting)

> 配套模板：`assets/script-template.md`。调性优先取 `profile.md`（机制见 `references/memory.md`）；用户给了品牌 / 平台 / 受众约束则以用户为准。

## 0. 默认骨架：故事型（所有场景通用）

**所有文案默认走故事骨架**。带货、种草等偏广告类场景，可以切换到 §2 的广告骨架。

### 为什么默认故事

用户要的不是"讲明白"，是"看了想联系"。不管什么场景——招主播、行业观察、主播日常、成功案例——让观众觉得"这公司懂行、真诚、靠谱"，主动来找你，靠的都是故事，不是道理。

| 讲道理 | 讲故事 |
|---|---|
| 直播行业前景好，收入可观 | 我躺够了，去试了，现在播了一个月，够交房租 |
| 找工作难，是因为赛道选错了 | 我投了三十份，回我的三个，还都是「不合适」 |
| 欢迎咨询了解详情 | 你要也躺累了，评论区说一声 |

### §0.1 叙事视角选择（**默认第一人称**）

视角决定"谁在说话"，直接影响代入感。默认**第一人称**（"我去年辞了..."），除非有充分理由切换。

| 视角 | 开头长什么样 | 什么时候选 | 视频里长什么样 |
|---|---|---|---|
| **① 第一人称口播（默认）** | "我去年辞了干了三年的..." | 所有场景，最通用 | 一个人对着镜头说话，真人实拍感 |
| **② 第三人称朋友故事** | "我有个朋友，投了三十份简历..." | 想讲故事但不想暴露自己（比如公司号不是个人号）；或故事主角和说话的人身份差大（比如朋友是宝妈，你是运营） | **字幕卡 + 人物画面**（不用画外音——画外音让承接断裂，用画面飘文字当第三人称叙述的替代品） |
| **③ 对话体** | 字幕卡 A："姐，我30岁了不知道干嘛。" 出镜 B："没事，我当年也是..." | 懂行姐姐/过来人聊真话；一镜到底的口播视频，出镜人设拉信任 | 出镜人对着镜头说话，像跟闺蜜视频（你那个阿岚就是这个） |
| **④ 行业观察/干货** | "做了三年直播运营，今天把真话摊开说..." | 建立行业话语权；吸引同行业关注 | 真人出镜 + 背后叠画面（数字、人物剪影） |
| **⑤ 设问体** | "你是不是也投了三十份简历没回音？" | 钩子型开头，抓精准人群 | 开头特写"卡住"的画面，然后口播 |
| **⑥ vlog 体** | （对着镜头自然说话）"今天跟你们说点事..." | 人设型账号；像随手拍的日常 | 手持微晃、真实感、脚本感弱 |
| **⑦ 数字清单体** | "三个能跑出来的类型：第一个脸皮厚的..." | 信息密度高、易传播 | 口播 + 字幕/画面浮层叠加 |

**怎么选**（按优先级）：
1. 用户明确说了视角 → 按他的
2. 用户没说 → **默认第一人称**，谁写的谁就是故事主角
3. 只有在"公司号不能以个人身份出镜""主角和说话人身份差太大"这些特殊情况才切第三人称

**不许偷懒**：不要连续三条都用"我有个朋友"——那不是视角选择，是没思考。换着来。

### 故事不是骨架，是微短剧剧本

**我之前错把"骨架"当成了故事——骨架是提纲，微短剧剧本才是真故事。**

微短剧三幕结构，每一幕都要有**具体画面细节**，能直接变成镜头：

| 幕 | 要写什么 | 不能偷懒写成 | 必须有 |
|---|---|---|---|
| **第一幕·起** | 一个具体的人，在一个具体场景里，面临一个具体困境 | "我没钱了" | 场景细节（出租屋什么样子、墙上有什么、桌上有什么）、数字（手机余额、账单金额）、环境音（窗外的声音） |
| **第二幕·承+转** | 她挣扎了什么（试了 A、B、C 都失败），跌入谷底，然后遇到转机（偶然看到什么、被人点拨、自己想通了） | "她投了三十份简历" | 每一次挣扎的画面（穿衬衫挤地铁、HR说什么、把简历揉成一团）；转机的具体触发点（那个姑娘说了什么具体的话、不是"但脸上那股劲儿"） |
| **第三幕·合** | 结果如何（不编数字，但要有变化）、结尾钩子 | "现在够交房租了" | 前后对比的细节（上次是揉简历的手，这次是笑着的梨涡）、具体变化点（第一次说完整句话没卡壳、后台显示观众 3 人） |

### 微短剧里的"钩子点"

每条视频都需要一个**让观众记住的具体细节**——不是模糊的"她很沮丧"，是"她按灭屏幕四次，第四次盯着那句'暂不匹配'看了三秒"。钩子点可以是：

- 一个重复的小动作（按灭屏幕×4、揉简历×3、坐起来又放下×2）
- 一个具体的数字（余额 127.6、投了 32 份、观众 3 人）
- 一个反差（她之前揉简历的手，现在举着手机笑）
- 一句不是口播旁白的真实声音（HR 说"应届生优先研究生"、弹幕飘"加油"）

**钩子点不是旁白里说出来的，是画面里演出来的。**

### 微短剧剧本 vs 口播脚本

| | 微短剧剧本（你要的） | 口播脚本（我之前出的） |
|---|---|---|
| 写法 | 每一句配画面，画面里有细节 | 从头到尾一个人对着镜头说话 |
| 内容饱满度 | 有挣扎、有转机、有对比、有钩子点 | 有叙事线但没画面支撑 |
| 视频时长 | 30–60 秒，内容密度高 | 30 秒就能讲完，但是空 |
| 情绪 | 观众跟着主角走，有代入感 | 观众"听你说一件事"，隔了一层 |

**对外内容类默认走微短剧剧本**，不是口播脚本。只有带货/种草才用口播或广告骨架。

### 微短剧三幕模板（填空式，**同一场景演完三幕**）

```
【起·场景+困境】
[选一个固定场景：出租屋/工位/宿舍/出租屋门口的台阶...]，[时间]，[环境细节]
[人物] 在 [做什么]，[具体困境：数字/画面/声音]
→ 画面钩子点（让观众记住的一个具体细节）

【承·挣扎·同一场景】
[还是同一个场景]，[时间流逝的证据：窗帘拉上了/外卖盒堆了/手机屏幕灭了又亮]
→ 用**人物状态变化**体现挣扎（不是换个场景演另一件事）
→ 钩子点：[同一个身体部位的动作变化]

【转·转机·同一场景】
[还是同一个场景/同一个位置]，[偶然发生的事：手机弹出一条视频/听到楼下有人说话/收到一条私信]
→ 钩子点：[触发她行动的那个具体画面/声音/字幕]

【合·变化·同一场景同一个位置】
[还是同一个位置]，[过了一段时间的证据：桌上多了东西/头发剪了/衣服换了但场景没变]
→ 对比变化：[之前的状态] vs [现在的状态]（**同一个人、同一个位置、同一个手/脸的变化**）
→ 钩子点：[前后对比的那个具体画面]
→ CTA 钩子
```

**核心规则**：起承转合在**同一个场景**里演完。变化的是**人物状态**（表情、动作、桌上的东西、手机内容），不是环境。环境越稳定，人物变化越突出——这才是微短剧里"串得起来"的承接。

### 只写目的，不写套路

结构定死了，每条文案都一个样。所以这里**不规定怎么写**，只说清要达成什么。

**唯一目的**：让看完的人来联系我们。不是"觉得这家公司还不错"，是"我想问一句怎么开始"。

由目的直接推出来三件事（不是规则，是结果）：

- **故事得真**：观众一眼看出是编的，就不会信，也不会来
- **"我们"得有用**：主角自己就能成，观众会觉得自己也行，不用找你
- **最后得有一个动作**：想联系的人不知道往哪走，等于白讲

**三条底线（合规问题，不可碰）**

1. 不写收入数字与承诺
2. 限流词干净
3. CTA 只有一个

其余全部自由：多长、从哪切入、痛到什么程度、转折放哪、谁来带、结尾说什么——自己判断。

动笔前只回答两个问题：

1. **这事会发生吗？**（动机有来路，转折不靠巧合）
2. **看完的人，知道下一步该干嘛吗？**

**想不出怎么讲，可以借用这些（不是必须，也不限于这些）**

| 讲法 | 长什么样 |
|---|---|
| 顺叙 | 最难的时候 → 被拉进来 → 现在 |
| 倒叙 | 先给现在（新住处、直播间、给家里转账），再回到出租屋 |
| 一句话切入 | 直接从朋友那句"你先来看一场"开始 |
| 对照式 | 同一张桌子 / 同一双手，前后两个状态剪在一起 |
| 对话式 | 只靠两句对话推进，画面补信息 |
| 时间戳式 | 第 1 天 / 第 7 天 / 第 30 天 |
| 物件视角 | 一只行李箱 / 一沓账单 / 一部手机串起全片 |

**最容易"差点意思"的三处（写完专门检查）**

- **痛不痛**：有没有一个具体数字或代价——余额八十三、走四站省两块、一顿饭是打折面包。只写"很难"等于没写。
- **转折有没有阻力**：她一开始不敢 / 不信 / 怕是先交钱的，被朋友硬拉去。太顺就是假。
- **结果有没有一个具象瞬间**：给妈妈买了件外套、搬出没窗户的隔断——比"能顾家""挺好的"有画面得多。

**去 AI 味（写完必查）**

AI 味不是用词问题，是**节奏和功能感**问题：

| AI 味 | 人话 |
|---|---|
| 每句都短、都用逗号切三段："毕业四个月，我交完房租水电，卡里剩八十三。" | 长短不齐，允许一口气说完："刚毕业我在杭州，房租一千八，一间没窗户的隔断。" |
| 排比三连："说挺好的，工作挺顺，吃得也好" | 只说一个："她一问钱够不够，我就说够。" |
| 每个细节都为剧情服务（走四站省两块） | 留一个**没用但真实**的细节："她穿上拍照发我，手都不知道往哪放。" |
| 旁白解释情绪："我很绝望" | 只给动作："挂了电话在楼道坐半天。" |
| 苦难标配：余额八十三、打折面包、没窗户的隔断 | 一个就够，另一个换成只属于这个人的（城市、算账方式、口头禅） |
| 30 秒硬塞完整故事 | 真实口述讲不完 30 秒，**宁可 45 秒**，别压缩成电报 |

允许并鼓励：口头语（就、反正、其实、真的、那种、吧）、说一半改口、重复、跑题一句、句尾语气词。

**真人视频：先过"这事会发生吗"**

句子像人话了，剧情还可能是假的。下面五条，一条不成立就重写：

| 检查 | 假的做法 | 真的做法 |
|---|---|---|
| 动机有来路 | 她去面试主播，正好被录用 | 刷到别人播 → 心想"这也能行" → 自己先偷偷试 |
| 先自己失败一次 | 被朋友一劝就去了，一学就会 | 手机架纸箱上，进来三个人走两个，说句"大家好"就冷场，自己关掉 |
| 转折不靠巧合 | 朋友恰好来楼下堵她、恰好让她试播 | 朋友刷到了她那场三个人的直播，发微信笑她 |
| "我们"有自然入口 | 空降一个"我们公司" | 朋友在同行、评论区、同城，顺着已有的关系进来 |
| 反应有延迟 | 听到坏消息立刻哭 | 先愣一下、笑一下、低头，过两秒才红眼 |

写之前先回答一句：**她为什么偏偏今天想干这个？** 答不上来，就是编的。

**生成前先写一行"这次怎么讲"**，再动笔。默认套顺叙就是偷懒，也是同质化的来源。

### 判断标准只有一个

写完问自己：**观众看完，是想联系我们，还是想自己干？**

| 写法 | 观众结论 | 判定 |
|---|---|---|
| 主角刷到别人 → 自己试 → 成功 | "我也行，不用找他们" | ❌ 废稿 |
| 主角试过、卡住 → 有人接住、公司教他 → 他成了 | "我自己搞不定，得找这群人" | ✅ 对 |

关键不是顺序，是**中间"被谁接住"这一步不能缺**，而且得有具体动作（教了什么、陪练了什么、复盘了什么）。缺了这步，就是励志鸡汤，不带来咨询。

### 结果段的限流防护（写死，不许碰）

> ⚠️ 这一段最容易触发限流，直接按这个来，不要改：
> - **禁止写收入数字与承诺**：月薪 X、提成 X%、月入过万、包就业——全删。
> - **不禁写生活细节**：余额、房租占比、通勤两小时、晚饭是打折面包——这些越具体越可信，但必须真实或用户确认过。"够交房租""能顾家""每月能往家里打点"属于可感知、不承诺的说法，优先用。
> - **禁止编结果**：故事可以编，结果必须是真实可验证的。用户提供了真实数据才写；没有就用默认说法。
> - **禁止对比贬损**：不要写"比之前多赚了多少"来制造落差，容易被判定为"高薪诱导"。

### 故事结尾不是"招人"，是给一个钩子

直接说"我们招人、来应聘"——那是硬伤，读者没有理由现在就联系。要给一个**让人好奇、门槛又低**的动作：

| 钩子类型 | 话术 | 为什么有效 |
|---|---|---|
| 资料钩子 | 私信我，发你一份《新人第一个月怎么过》 | 白拿东西，不亏 |
| 群钩子 | 评论区打"想听"，拉你进群，群里发真实数据 | 群 = 有更多信息 |
| 剧透钩子 | 关注我，下条讲"主播一天到底在干嘛" | 想知道下文 |
| 收入钩子 | 想知道这行到底怎么算钱，评论区问 | 直接利益 |
| 判断钩子 | 不确定自己适不适合？私信我，三分钟帮你看 | 降低门槛 |

**原则**：先让人"来了解"，再谈"来合作"。别一步到位。

> 故事套路和结尾钩子的完整库，见 `references/story-types.md`。

### 骨架生成时的限流防护（黑名单自动替换）

下面这些词一出现就容易被平台限流，骨架生成时**自动替换**，不许手动写：

| 黑名单词（限流） | 自动替换为 |
|---|---|
| 招主播 / 招募 / 招聘 | 我们在找 / 想试试的来 |
| 底薪 / 月薪 / 工资 | 待遇面谈 / 结构具体聊 |
| 月入过万 / 高薪 / 收入可观 | 够交房租 / 能顾家 |
| 简历 / 投递 / 入职 | 私信聊 / 来了解 |
| 五险一金 / 包吃住 | （不写，用其他钩子代替） |
| 加微信 / 留电话 | 评论区说一声 / 私信你 |
| 包学会 / 包分配 | （不写，换"带你练"） |

> 如果用户明确要求保留某个黑名单词，**停下来告诉他限流风险**，让他自己选：
> "这句会被限流，你要我换掉还是原样写（原样发出去大概率没人看到）？"

## 1. 先定场景，再定平台

### 1.1 场景 × 目标 × 骨架

场景比平台优先，它决定骨架。默认用故事骨架，广告骨架（§2）只在带货/种草时按需切换。

| 场景 | 核心目标 | 骨架 | 典型 CTA |
|---|---|---|---|
| **对外内容（默认）** | 让观众觉得公司懂行、真诚、靠谱，主动联系 | 故事型（§0） | 私信 / 评论 / 关注 |
| 带货 | 成交 | 钩子 → 痛点 → 卖点 → 信任 → CTA | 下单 |
| 种草 | 激发兴趣 | 场景 → 体验 → 对比 → 推荐 | 关注 / 收藏 |
| 品牌 | 建立认知 | 理念 → 证据 → 愿景 | 了解 |
| 活动 | 让人到场 | 时间 → 看点 → 福利 → 怎么来 | 报名 / 到场 |
| 秀场 | 留住人、给情绪价值 | 开场钩子 → 互动 → 情绪高潮 → 关注/感谢 | 关注 / 灯牌 |

> **对外内容**包括但不限于：想入行的人、想换平台的主播、行业好奇者、对公司感兴趣的任何人。统一走故事骨架，不管具体是谁。

### 1.1.1 原文的目标不能改

用户给了文案，**文案就是目标**。你可以改表达，不能改它想干的事。

| 可以改 | 不能改 |
|---|---|
| 说法（「招主播」→「我们在找主播」） | 目标（招人还是卖货） |
| 结构顺序、节奏、长度 | 受众（宝妈还是年轻人） |
| 删限流词、换平台内 CTA | 岗位、卖点、待遇方向 |
| 语气、口语化程度 | 文案里的人设、场景、承诺范围 |

**判断标准**：改完之后，读的人要做的事变了吗？

- 还是来联系 → 对
- 变成「只是看个热闹」 → **跑题了**，改回去

### 1.2 平台

抖音 / 快手 / 视频号 / 小红书（决定时长、结构、语言密度）。

### 1.3 目标

涨粉、私域、成交、还是品牌曝光。

## 2. 广告骨架（带货 / 种草专属）

> 这是**广告类场景的骨架**，对带货、种草最好用。对外内容类不要用这个，用 §0 的故事骨架。

| 段落 | 作用 | 时长占比 | 写法要点 |
|---|---|---|---|
| 钩子 (Hook) | 前 3 秒留住人 | 10% | 反常识 / 冲突 / 悬念 / 直接给利益 |
| 痛点 (Pain) | 共鸣 + 放大需求 | 20% | 具体场景、用户原话 |
| 卖点 (Value) | 产品 / 内容价值 | 40% | 1–3 个核心卖点，配证据 |
| 信任 (Trust) | 消除顾虑 | 20% | 资质 / 数据 / 口碑 / 对比 |
| CTA | 行动指令 | 10% | 关注 / 下单 / 进直播间，单一明确 |

## 3. 分平台要点（可按公司实际偏好调整）

- **抖音**：节奏快、前 3 秒定生死、强情绪、完播率优先。
- **快手**：老铁信任、真实接地气、私域沉淀。
- **视频号**：社交裂变、熟人信任、偏中长干货。
- **小红书**：封面 + 标题党（合规内）、种草笔记体、强搜索词。

## 4. 话术资产

> 下面是**通用底稿**，不是成品。按你的品类替换主语就能用；公司有自有的就覆盖掉。

### 4.1 钩子库（前 3 秒）

| 类型 | 句式 | 例 |
|---|---|---|
| 反常识 | 「[常识] 其实错了，[真相]」 | 「洗面奶不是泡沫越多越好」 |
| 利益直给 | 「[时长] 教你 [省/赚/避] 多少」 | 「30 秒教你避开 90% 人踩的坑」 |
| 自曝冲突 | 「我再也不 [做某事] 了，因为 [原因]」 | 「我再也不买大牌粉底了」 |
| 悬念留白 | 「[过程] 里我差点放弃」 | 「试了 11 家，只有一家我敢推荐」 |
| 场景共鸣 | 「你有没有过 [具体场景]」 | 「刚化完妆出门就花？」 |
| 身份锁定 | 「如果你是 [人群]，这条必须看完」 | 「干皮姐妹先别划走」 |
| 数字清单 | 「[N] 个方法，第 [N] 个最狠」 | 「3 个选品思路，第 2 个帮我清了库存」 |

> 改造方法：把方括号换成你的品类主语。**一条文案只用一个钩子**，别叠加。
> 自检：3 秒内能不能让人知道「这跟我有关」。

### 4.2 卖点支撑（每条卖点必须配证据）

| 说法 | 证据类型 | 不合格的样子 |
|---|---|---|
| 「保湿 12 小时」 | 检测报告 / 实测视频 | 只说「很保湿」 |
| 「30 天可退」 | 平台规则截图 / 客服话术 | 只说「放心买」 |
| 「工厂直发」 | 工厂实拍 / 资质 | 只喊「没有中间商」 |

> 没有证据的卖点 = 空承诺。删掉，或降级成「体验描述」。

### 4.3 CTA 库

| 目标 | 话术 | 备注 |
|---|---|---|
| 关注 | 「关注我，[下一个具体价值]」 | 比「点个关注」有效 |
| 进直播间 | 「今晚 8 点直播间，[具体福利/名额]」 | 给时间 + 具体东西 |
| 下单 | 「下方[位置]，[稀缺/时限]」 | 喊一次就够，别喊三次 |
| 评论互动 | 「评论区打[关键词]，我挨个回」 | 涨互动权重 |
| 私域 | **平台内引导**；站外导流见 `compliance.md` §4 | 别写微信号 |

## 5. 自检清单

- [ ] 骨架选对了：对外内容用故事型（目的与底线见 §0），带货/种草用广告骨架
- [ ] 故事型两个问题：这事会发生吗？"我们"在故事里有没有实际作用？
- [ ] 像不像人说的话：没有短句堆砌、排比、每段一个功能
- [ ] 广告骨架：前 3 秒钩子成立、卖点有证据、CTA 单一明确
- [ ] **限流词黑名单过了一遍**：没有「底薪」「月入过万」「简历」「加微信」等
- [ ] 合规：极限词 / 功效宣称 / 导流 已标红排查（通用硬规则，必须标红）
- [ ] 平台适配（时长、结构、语气）
