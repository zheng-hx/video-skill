# 写文案工作流 (Copywriting)

> 配套模板：`assets/script-template.md`。调性优先取 `profile.md`（机制见 `references/memory.md`）；用户给了品牌 / 平台 / 受众约束则以用户为准。

## 1. 先定类型，再定平台

### 1.1 类型 × 结构

类型比平台优先，它决定骨架；平台只决定节奏和语言密度。

| 类型 | 核心目标 | 结构重点 | 典型 CTA |
|---|---|---|---|
| **择业** | 让人对行业产生好奇，来私信咨询 | 处境 → 行业观察 → 破除误解 → 真实情况 → 想聊就来 | 私信 / 评论 |
| 招募（硬） | 让人直接投简历 | 待遇 → 条件 → 机会 → 怎么来 | 投递；⚠️ 易被限流 |
| 带货 | 成交 | 痛点 → 卖点 → 证据 → 促单 | 下单 |
| 种草 | 激发兴趣 | 场景 → 体验 → 对比 → 推荐 | 关注 / 收藏 |
| 人设 | 建立记忆点 | 反差 → 故事 → 态度 | 关注 |
| 引流 | 拉到直播间 / 私域 | 钩子 → 利益 → 路径 | 私信 / 进播 |
| 品牌 | 建立认知 | 理念 → 证据 → 愿景 | 了解 |
| 活动 | 让人到场 | 时间 → 看点 → 福利 → 怎么来 | 报名 / 到场 |
| 剧情 | 让人看完 | 冲突 → 转折 → 落点 | 跟看 |
| 秀场 | 留住人、给情绪价值 | 开场钩子 → 互动 → 情绪高潮 → 关注/感谢 | 关注 / 灯牌 |

> 认不出类型时用**通用结构**：钩子 → 痛点 → 价值 → 证据 → CTA。它对大多数类型都成立。

### 1.1.1 原文的目标不能改

用户给了文案，**文案就是目标**。你可以改表达，不能改它想干的事。

| 可以改 | 不能改 |
|---|---|
| 说法（「招主播」→「我们在找主播」） | 目标（招人还是卖货） |
| 结构顺序、节奏、长度 | 受众（宝妈还是年轻人） |
| 删限流词、换平台内 CTA | 岗位、卖点、待遇方向 |
| 语气、口语化程度 | 文案里的人设、场景、承诺范围 |

**判断标准**：改完之后，读的人要做的事变了吗？

- 还是来应聘 → 对
- 变成「了解这行」 → **跑题了**，改回去

### 目标有风险时怎么办

不是把目标改掉，是用合规说法表达同一个目标：

| 原文（限流） | 错的改法 | 对的改法 |
|---|---|---|
| 招主播，底薪 6000 | 改成「这行是什么样」（目标没了） | 「我们在找主播，底薪加提成，具体面谈」（目标还在） |
| 加微信领小样 | 改成「关注我」（目标没了） | 「评论区扣小样，我私信你」（还是领小样） |

如果怎么换说法都绕不开红线（比如就是要写「月入过万」），**停下来问用户**：
> 「这句写进去会被限流，你要的是招人，我可以保留招聘、去掉数字；或者你坚持写数字，那建议发招聘平台，不发抖音。你选哪个？」

**绝不擅自替用户换目标。**

### 1.1.2 默认用故事，不用道理

用户要的不是「讲明白」，是「看了想联系」。

| 讲道理 | 讲故事 |
|---|---|
| 找工作难，是因为赛道选错了 | 我投了三十份，回我的三个，还都是「不合适」 |
| 直播行业前景好，收入可观 | 我躺够了，去试了，现在播了一个月，够交房租 |
| 欢迎咨询了解详情 | 你要也躺累了，评论区说一声 |

**故事型六段骨架**：

1. **处境**：一个具体的人，在做一件具体的事（躺出租房、投简历、半夜刷手机）
2. **卡住**：她卡在哪（没人回、被说「不合适」）
3. **自我怀疑**：她开始怀疑自己（是不是我不行）
4. **看见别人**：她发现有个人走了另一条路（那一个月拿一万多的姑娘）
5. **试了 + 结果**：她试了，结果是什么（播了一个月，够交房租）
6. **邀请**：一句话，让人想联系（评论区说一声，我私信你）

**核心：主角是人，不是行业。** 读者代入的是人，没人会代入「赛道」。

**人称**：用「我」最亲；其次是「我一个朋友」。**少用「你」**——「你」是在教育人，故事是在分享。

**困难必须写**。「前三个月没人看，说话说到嘴干」这句不能删。只讲好的，评论区第一条就是「骗人的」。

**红线**：故事可以编，结果不能编。要写具体收入，用户提供真实数据才写，并且标来源；没有就写「够交房租」这种可感知但不承诺的说法。

### 1.2 平台

抖音 / 快手 / 视频号 / 小红书（决定时长、结构、语言密度）。

### 1.3 目标

涨粉、私域、成交、还是品牌曝光。

## 2. 通用脚本结构（钩子 → 痛点 → 卖点 → 信任 → CTA）

> 这是**默认骨架**，对带货、种草最好用。招募、人设、活动等类型按 §1.1 的结构走，别硬套。

| 段落 | 作用 | 时长占比 | 写法要点 |
|---|---|---|---|
| 钩子 (Hook) | 前 3 秒留住人 | 10% | 反常识 / 冲突 / 悬念 / 直接给利益 |
| 痛点 (Pain) | 共鸣 + 放大需求 | 20% | 具体场景、用户原话 |
| 卖点 (Value) | 产品 / 内容价值 | 40% | 1–3 个核心卖点，配证据 |
| 信任 (Trust) | 消除顾虑 | 20% | 资质 / 数据 / 口碑 / 对比 |
| CTA | 行动指令 | 10% | 关注 / 下单 / 进直播间，单一明确 |

## 3. 分平台要点（可按公司实际偏好调整）

- **抖音**：节奏快、前 3 秒定生死、强情绪、完播率优先。
- **快手**：老铁信任、真实接地气、私域沉淀。
- **视频号**：社交裂变、熟人信任、偏中长干货。
- **小红书**：封面 + 标题党（合规内）、种草笔记体、强搜索词。

## 4. 话术资产

> 下面是**通用底稿**，不是成品。按你的品类替换主语就能用；公司有自有的就覆盖掉。

### 4.1 钩子库（前 3 秒）

| 类型 | 句式 | 例 |
|---|---|---|
| 反常识 | 「[常识] 其实错了，[真相]」 | 「洗面奶不是泡沫越多越好」 |
| 利益直给 | 「[时长] 教你 [省/赚/避] 多少」 | 「30 秒教你避开 90% 人踩的坑」 |
| 自曝冲突 | 「我再也不 [做某事] 了，因为 [原因]」 | 「我再也不买大牌粉底了」 |
| 悬念留白 | 「[过程] 里我差点放弃」 | 「试了 11 家，只有一家我敢推荐」 |
| 场景共鸣 | 「你有没有过 [具体场景]」 | 「刚化完妆出门就花？」 |
| 身份锁定 | 「如果你是 [人群]，这条必须看完」 | 「干皮姐妹先别划走」 |
| 数字清单 | 「[N] 个方法，第 [N] 个最狠」 | 「3 个选品思路，第 2 个帮我清了库存」 |

> 改造方法：把方括号换成你的品类主语。**一条文案只用一个钩子**，别叠加。
> 自检：3 秒内能不能让人知道「这跟我有关」。

### 4.2 卖点支撑（每条卖点必须配证据）

| 说法 | 证据类型 | 不合格的样子 |
|---|---|---|
| 「保湿 12 小时」 | 检测报告 / 实测视频 | 只说「很保湿」 |
| 「30 天可退」 | 平台规则截图 / 客服话术 | 只说「放心买」 |
| 「工厂直发」 | 工厂实拍 / 资质 | 只喊「没有中间商」 |

> 没有证据的卖点 = 空承诺。删掉，或降级成「体验描述」。

### 4.3 CTA 库

| 目标 | 话术 | 备注 |
|---|---|---|
| 关注 | 「关注我，[下一个具体价值]」 | 比「点个关注」有效 |
| 进直播间 | 「今晚 8 点直播间，[具体福利/名额]」 | 给时间 + 具体东西 |
| 下单 | 「下方[位置]，[稀缺/时限]」 | 喊一次就够，别喊三次 |
| 评论互动 | 「评论区打[关键词]，我挨个回」 | 涨互动权重 |
| 私域 | **平台内引导**；站外导流见 `compliance.md` §4 | 别写微信号 |

## 5. 自检清单

- [ ] 平台适配（时长、结构、语气）
- [ ] 前 3 秒钩子是否成立
- [ ] 卖点有证据支撑，无空口承诺
- [ ] 合规：极限词 / 功效宣称 / 导流 已标红排查（通用硬规则，必须标红）
- [ ] CTA 单一明确
- [ ] 与主播调性一致（串联模式）

## 6. 平台细分文案模板（复用外部生态）

抖音 / 视频号 / 小红书等**具体平台**的文案与排版模板，已有成熟第三方 Skill 合集（如 `lqmeter/awesome-social-media-skills`），按需复用即可，见 `references/ecosystem.md`。本文件保留**跨平台通用框架**，不重复造轮子。
