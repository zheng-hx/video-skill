# 招人内容打法

> 一句话目标：**让看的人主动来找你，想入职、想入行。**
> 除此之外全是手段——故事、台词、剧情、人设，都能换。

## 1. 什么能变，什么不能变

| 能变 | 不能变 |
|---|---|
| 哪个故事（九种轮换） | 目标：让人来联系、想入职 |
| 主角是谁（宝妈 / 被裁 / 跳槽 / 转行） | 岗位是真的，不是编的 |
| 台词、节奏、长度 | 待遇方向真实，不编收入 |
| 场景、人设、城市 | 合规底线 |
| 结尾钩子（五种轮换） | — |

**判断有没有跑偏**：改完这一版，看的人要做的事还是「来找你问入职」吗？变成「了解这行就好」就是跑偏。

## 2. 一条招人视频的骨架

1. **钩子（前 3 秒）**：一个具体场景，让人对号入座（夜里十一点刷直播、投了三十份简历）
2. **故事六段**：处境 → 卡住 → 自我怀疑 → 看见别人 → 试了 + 结果
3. **转折**：她决定试的那一刻（把「大家好」换成「你来啦」）
4. **钩子（结尾）**：不招人，给一个了解的理由（进群看真实排班、私信领新人攻略）
5. **落点**：只留一个动作

## 3. 验收：这条能不能让人来找你

看完这条，一个正在找出路的人会不会：

- [ ] 觉得「这说的就是我」
- [ ] 想知道「她怎么做到的」
- [ ] 有一个低门槛的动作能做（评论 / 私信 / 进群）

三条全中才算合格。**只中第一条，是共鸣，不是转化。**

## 4. 什么可以怎么换

| 维度 | 换法 |
|---|---|
| 故事类型 | 九种轮换：转行 / 跳槽 / 新手 / 宝妈 / 被裁 / 副业 / 学历 / 对比 / 幕后 |
| 主角 | 换年龄、职业、城市、处境 |
| 冲突 | 换具体卡点（没人看 / 被裁 / 家人反对 / 学历不够） |
| 结果 | 换可感知的说法（够交房租 / 能顾家 / 拿到第一笔提成） |
| 结尾钩子 | 五种轮换：资料 / 群 / 剧透 / 收入 / 判断 |

## 5. 不能动的底线

- 岗位是真的，不是编的
- 收入不编数字
- 不点名别家、不拉踩
- 不承诺「包学会」「月入过万」
- 困难必须写，只讲好的没人信

## 6. 发出去没人来，怎么调

| 现象 | 多半是 | 怎么改 |
|---|---|---|
| 同一条发三次都没人问 | 故事不对味 | 换故事类型 |
| 有人看、没人问 | 结尾钩子门槛太高 | 把「来应聘」换成「来了解」 |
| 有人问、不来 | 没讲清这活到底干嘛 | 补一段「我一天到底在做什么」 |
| 评论区说「假的」 | 困难写少了，或结果吹了 | 补困难、去掉数字 |
