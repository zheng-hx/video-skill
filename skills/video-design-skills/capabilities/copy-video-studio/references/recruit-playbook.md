# 故事型文案主线方法论

> 一句话目标：**让看的人主动来找你，想入行、想合作、想了解。**
> 除此之外全是手段——故事、台词、剧情、人设，都能换。

## 1. 什么能变，什么不能变

| 能变 | 不能变 |
|---|---|
| 哪个故事（九种轮换，见 `story-types.md`） | 目标：让人来联系、想了解 |
| 主角是谁（宝妈 / 被裁 / 跳槽 / 转行） | 事实是真的，不是编的 |
| 台词、节奏、长度 | 结果真实，不编收入数字 |
| 场景、人设、城市 | 合规底线（见 `compliance.md`） |
| 结尾钩子（五种轮换） | — |

**判断有没有跑偏**：改完这一版，看的人要做的事还是「来找你问 / 想了解」吗？变成「只是看个热闹」就是跑偏。

## 2. 一条故事型文案要成立的条件

骨架见 `copywriting.md` §0——**只写目的，不锁套路**：

- **目的**：看完的人来联系我们
- **底线**：不写收入数字与承诺 / 限流词干净 / CTA 只有一个
- **两个问题**：这事会发生吗？看完知道下一步干嘛吗？

怎么讲、多长、从哪切入、痛到什么程度，自己判断。想不出时再翻 §0 的讲法清单。

## 3. 验收：这条能不能让人来找你

看完这条，一个正在找出路的人会不会：

- [ ] 觉得「这说的就是我」
- [ ] 想知道「她怎么做到的」
- [ ] 有一个低门槛的动作能做（评论 / 私信 / 进群）

三条全中才算合格。**只中第一条，是共鸣，不是转化。**

## 4. 什么可以怎么换

| 维度 | 换法 |
|---|---|
| 故事类型 | 九种轮换：转行 / 跳槽 / 新手 / 宝妈 / 被裁 / 副业 / 学历 / 对比 / 幕后 |
| 主角 | 换年龄、职业、城市、处境（客服、导购、店员、上班族……） |
| 冲突 | 换具体卡点（没人看 / 被裁 / 家人反对 / 学历不够 / 想换活法） |
| 结果 | 换可感知的说法（够交房租 / 能顾家 / 拿到第一笔提成） |
| 结尾钩子 | 五种轮换：资料 / 群 / 剧透 / 收入 / 判断 |

## 5. 不能动的底线

- 事实是真的，不是编的（岗位、主播状态、工作方式）
- 结果不编具体数字（见 `copywriting.md` §0 的限流防护）
- 不点名别家、不拉踩
- 不承诺"包学会""月入过万"
- 困难必须写，只讲好的没人信

## 6. 发出去没人来，怎么调

| 现象 | 多半是 | 怎么改 |
|---|---|---|
| 同一条发三次都没人问 | 故事不对味 | 换故事类型 |
| 有人看、没人问 | 结尾钩子门槛太高 | 把"来应聘"换成"来了解" |
| 有人问、不来 | 没讲清这活到底干嘛 | 补一段"我一天到底在做什么" |
| 评论区说"假的" | 困难写少了，或结果吹了 | 补困难、去掉数字 |
