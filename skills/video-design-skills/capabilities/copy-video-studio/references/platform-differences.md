# 平台差异

> 同一句话，四个平台四个结果。别拿抖音的经验套小红书。

## 1. 红线松紧对照

| 维度 | 抖音 | 快手 | 视频号 | 小红书 |
|---|---|---|---|---|
| 站外导流 | 严 | 较严 | **极严**（诱导分享） | **极严**（最狠） |
| 招工 / 招聘 | 严（易限流） | 较松 | 中 | 严 |
| 医疗功效 | 严 | 严 | 严 | **极严** |
| 诱导互动 | 点关注 / 抽奖 | 类似抖音 | **诱导分享最重** | 诱导关注 |
| 极限词 | 严 | 严 | 严 | 严 |
| 擦边 | 严 | 相对宽 | 严 | 严 |

## 2. 内容偏好不同

| 平台 | 适合什么 | 不适合什么 |
|---|---|---|
| 抖音 | 15–60 秒，快节奏，强钩子 | 长铺垫、慢叙事 |
| 快手 | 30–60 秒，真实、接地气、老铁人设 | 精致到失真的内容 |
| 视频号 | 30–120 秒，熟人转发，情感/知识 | 硬广、诱导分享 |
| 小红书 | 图文 + 短视频，种草、清单、测评 | 招聘、硬推销 |

## 3. 画幅

| 平台 | 主画幅 | 备注 |
|---|---|---|
| 抖音 | 9:16 | 全屏沉浸 |
| 快手 | 9:16 | 同上 |
| 视频号 | 9:16 | 封面单独做 |
| 小红书 | 3:4 或 9:16 | 图文 3:4 更吃香 |

## 4. 怎么用

1. 生成前先确认平台——不知道就问一句，这决定后面所有写法。
2. 规则快照按平台分开存：`~/.video-design/rules/<平台>.md`。
3. 没有该平台快照时，先按这份差异表保守写，并说明「这个平台的细则还没刷」。
4. 同一内容跨平台发 → 每个平台单独改一遍，别一份通投。

## 5. 择业/招工类特别说明

- **抖音**：必须走择业路线，硬招工基本限流。
- **快手**：相对宽松，但仍不建议写薪资承诺；「老铁」风格可用。
- **视频号**：可以提岗位，但不要诱导转发。
- **小红书**：招聘内容基本不做，改「职业分享 / 转行经历」。
