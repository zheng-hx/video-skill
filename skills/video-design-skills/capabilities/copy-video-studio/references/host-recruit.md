# 主播筛选与面试方法论

> 这是**行业参考**，不是文案/视频产出的直接内容。当你需要评估主播候选人、设计面试流程时用。
> 配套 JD 模板在同目录 `../assets/host-jd-template.md`，人工复制使用。

## 1. 岗位类型与画像维度

先确认岗位类型，再据此定义画像（不同品类画像差异大）：

| 岗位类型 | 核心能力侧重 | 典型画像关键词 |
|---|---|---|
| 带货主播 | 转化力、产品讲解、逼单 | 镜头感强、抗压、熟品类 |
| 秀场 / 娱乐 | 互动、才艺、留人 | 有趣、有才艺、情商高 |
| 知识 / 专业 | 专业度、表达、信任 | 行业背景、逻辑清晰 |
| 本地生活 | 探店、地域亲和力 | 本地达人、真实感 |

**画像维度（JD 与面试评估通用）**：
人设 / 外形 / 镜头感 / 表达力 / 品类专业度 / 抗压与稳定性 / 配合度 / 已有粉丝基础。

## 2. 产出清单

1. **招募 JD**：用 `copy-video-studio/assets/host-jd-template.md`。
2. **渠道招募话术**：用于招聘平台 / 社群 / 私信的短文案（痛点 + 待遇 + 行动指令）—— 但**对外内容类话术走 copy-video-studio 的故事骨架**，不走这里。
3. **简历 / 作品筛选 checklist**：按画像维度打勾，快速初筛。
4. **面试评估表 + 打分卡**：维度打分（1–5）+ 加权重算总分 + 一票否决项。
5. **候选人档案**：沉淀人设、调性、适配平台，供 copy-video-studio 定调性复用。

## 3. 面试评估维度（建议）

| 维度 | 权重 | 考察方式 |
|---|---|---|
| 镜头感 / 表现力 | 25 | 即兴口播 1 分钟 |
| 品类专业度 | 20 | 抽问产品 / 行业 |
| 转化 / 留人能力 | 30 | 模拟带货 / 互动 |
| 抗压 / 稳定性 | 15 | 情景压力题 |
| 配合 / 学习意愿 | 10 | 沟通观感 |

> 上面是**带货主播**的默认权重，直接能用。按岗位类型微调：
> 秀场娱乐把「转化」降到 15、把「表现力」提到 35；知识类把「专业度」提到 35、把「转化」降到 20。
> 调整后权重合计必须为 100。
>
> 一票否决项（命中任一条直接淘汰）：形象或定位严重不符、无法满足直播时段、对所售品类有合规风险。

## 4. 流程建议

`明确岗位 → 写 JD（用顶层模板）→ 发渠道（对外内容走 copy-video-studio）→ 初筛 checklist → 面试打分 → 出候选人档案`。
串联模式下，候选人档案自动流转给写文案环节作为调性输入。
