# 单条剧情视频剧本格式

> 交付物是**剧本**，不是文案。
>
> **每条视频独立**——不是连续剧，没有第一集第二集。一条讲完一个完整的小故事，
> 不设前情、不留下集钩子、不靠「敬请期待」。
>
> 格式照行业剧本走：场景头 + 镜头 + 对白。

## 1. 格式

```markdown
## 场景 1：出租房 · 内 · 日

♪ 窗外偶尔有车声

△ 中景：窗帘拉着，屋里是暗的。她躺在床上刷手机。

**她**：（把手机举高，只露出脸和天花板）在上班呢，妈，中午休息。

△ 特写：手机被扣在枕头上，屏幕还亮着。

——接场景 2：她翻身坐起来，套上外套出门。
```

三样东西：

| 元素 | 写法 | 只写什么 |
|---|---|---|
| 场景头 | `场景 N：地点 · 内/外 · 日/夜` | 地点、内景还是外景、白天还是夜里 |
| 镜头 | `△ 景别：画面` | 看得见的东西，不写心理活动 |
| 对白 | `**角色**：（动作/表情）台词` | 从她嘴里出来的话 |
| 配乐 | `♪ 描述` | 有就写，没有不写 |

## 2. 三条规矩

1. **真实**：这个地方她真的会去吗？出租房、图书馆、阳台、便利店——不是地铁闸机口。
2. **连贯**：上一场最后一个动作，下一场从这儿接。换地方要交代（人没走远 / 同一部手机 / 字幕写时间）。
3. **不旁白**：话从人物嘴里出来。不写「旁白：她心里想」。

## 3. 时长 → 场数

| 时长 | 场数 | 每场 | 装什么 |
|---|---|---|---|
| 15 秒 | 2–3 场 | 5–7 秒 | 一个处境 + 一个转折 |
| 30 秒 | 4–5 场 | 6–8 秒 | 处境 → 转折 → 一个结果 |
| 45 秒 | 6–7 场 | 6–8 秒 | 再加一次翻车 + 一次再试 |
| 60 秒 | 8 场 | 6–8 秒 | 完整起承转合 |

## 4. 一场只干一件事

- 一场一个主动作，最多带一个反应。
- 不在同一个场景里塞两个转折。
- 场尾留一句「接下去」，让下一场有地方落。

## 5. 自检

- [ ] 场景头写全了（地点 / 内外 / 日夜）
- [ ] 每场至少一个 △ 镜头
- [ ] 台词全从人物嘴里出来
- [ ] 上一场结束的动作 = 下一场开始的动作
- [ ] 场景是她真的会去的地方
- [ ] 场数对得上时长
