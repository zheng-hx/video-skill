## 官方明确的违规类型

| 类型 | 具体表现 |
|---|---|
| 发布违规商业内容 | 诱导互动、不真实信息、低俗、引人不适、价值导向不良 |
| 非原创 | 抄袭、搬运、改一改就当自己的 |
| 劣质营销信息 | 功效虚假夸张、错误价格对比、博眼球营销 |
| 不鼓励内容 | 拼接网络图片、低成本粗劣特效、无实质内容 |
| 作弊 | 刷播放/刷粉/刷转评赞、诱导点赞收藏分享关注、录屏挂播 |
| 投放劣质商品 | 禁售商品、假冒商品 |

## 处罚阶梯（官方）

| 级别 | 措施 |
|---|---|
| 轻度 | 警告 |
| 中度 | 限制变现：关闭变现权限、禁挂商业标签、限制提现、减少曝光；15 天 |
| 重度 | 同上，30 天起；再犯加重，可封禁 |
| 风险行为 | 冻结全部款项、清空账号信息、永久封禁功能 |

## 对文案的影响

1. 招人类：走择业路线，不谈岗位和钱（见 `copywriting.md` §1.1.1）。
2. 带货类：功效写成体验描述，不承诺效果。
3. 导流类：站外联系方式全部换平台内入口。
4. 互动类：不诱导点赞关注，靠内容本身留人。
