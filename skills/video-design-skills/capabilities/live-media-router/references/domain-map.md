# 自媒体 / 直播领域地图

> 这张图回答一个问题：**这个领域从头到尾有哪些活，你现在站在哪一步。**
> 每一环都标了「有没有技能」——标缺口的就是真没有，谁也别装作会。

## 全链路

```
定位 → 选题 → 内容生产 → 发布 → 直播 → 投流 → 复盘 → 变现
```

## 逐环清单

| # | 环节 | 交付物长什么样 | 技能 | 备注 |
|---|---|---|---|---|
| 1 | 账号定位 | 赛道、人设、对标账号、差异化一句话 | ❌ 缺口 | 决定后面所有事，别跳 |
| 2 | 选题 | 选题库、热点日历、爆款拆解 | ❌ 缺口 | |
| 3 | 内容生产 | 脚本、口播稿、分镜、成片 | ✅ `copy-video-studio` | |
| 4 | 发布 | 封面、标题、发布节奏 | ❌ 缺口 | |
| 5 | 直播 | 排品表、场控流程、憋单话术 | ❌ 缺口 | 和 ③ 的「视频」不是一回事 |
| 6 | 招主播 | JD、筛选 checklist、面试打分卡 | ✅ `live-media-ops` ① | |
| 7 | 投流 | 千川 / 随心推计划、出价、ROI | ❌ 缺口 | |
| 8 | 复盘 | 场观、停留、转化漏斗、逐场对比 | ❌ 缺口 | |
| 9 | 变现 | 带货、广告、私域承接 | ❌ 缺口 | |

> 「缺口」= 现在没有对应技能。要用只能临时用通用方法做，不沉淀。

## 从哪一步开始

先问一句：**你现在有账号吗？**

| 你的状态 | 从哪开始 |
|---|---|
| 还没号 / 刚注册 | 1 定位 |
| 有号但没流量 | 2 选题 + 4 发布 |
| 有流量但不成交 | 5 直播 + 7 投流 |
| 想招人来做 | 6 招主播 |
| 已经能跑，想放大 | 7 投流 + 8 复盘 |

## 每一步最少要知道的三件事

| 环节 | 必须问清 |
|---|---|
| 定位 | 平台、品类、你有什么别人没有的 |
| 选题 | 平台、目标人群、最近爆过什么 |
| 内容 | 平台、时长、这条要干嘛 |
| 直播 | 品类、客单价、主播有没有经验 |
| 投流 | 预算、目标 ROI、能烧多久试错 |
| 复盘 | 你要看哪一场、和谁比 |

## 常见误区（遇到要提醒，但别教训人）

- 定位没定就急着写脚本 → 写十条废十条
- 把「直播」当成「短视频」→ 排品和场控是完全另一套
- 数据复盘只看场观 → 停留和转化率才是命门
- 招到人再想内容 → 顺序反了，应该先定人设，再招匹配的人

## 维护说明

新增技能时改三处：本文件对应行的「技能」列、`SKILL.md` 的路由表、技能自己。三处不同步，路由就会指错。
