# 自媒体 / 直播领域入口 (live-media-router)

> 这个技能只干一件事：**听清你要干嘛，然后把你交给能干这件事的那只手。**
> 它自己不出稿、不写脚本、不排分镜——那些是下游的事。

## 什么时候用我

满足任意一条：

- **领域级需求**：「我想做自媒体」「直播怎么起号」「这个账号该怎么运营」
- **跨环节需求**：「又要定位又要脚本」「从招人到出片」
- **不确定该找谁**：「这活该用哪个技能」「有没有能做这件事的技能」
- **问有没有**：「你能做涨粉吗」

## 什么时候别用我

用户已经在说具体活的时候：「帮我写个抖音口播」「招主播的 JD」「生成视频分镜」。

→ 直接进对应技能，别绕这一层。多绕一层只会多问一轮废话。

## 第一步：判断在不在领域内

命中任意一条即算：

| 维度 | 判断依据 |
|---|---|
| 平台 | 抖音 / 快手 / 视频号 / 小红书 / B 站 / 淘宝直播 / TikTok / YouTube |
| 动作 | 定位 / 选题 / 脚本 / 开播 / 投流 / 涨粉 / 转化 / 复盘 / 招主播 / 出片 |
| 角色 | 主播 / 运营 / 编导 / 投手 / 内容创作者 |

三条都不沾 → 直接说「这不在我这块」，不硬接。

## 第二步：查路由表

| 用户想干的 | 去哪 | 现在有吗 |
|---|---|---|
| 招主播 / 写 JD / 筛简历 / 面试打分 | `live-media-ops` ① | ✅ |
| 写文案 / 口播脚本 / 带货话术 / 种草文案 | `copy-video-studio` | ✅ |
| 把文案做成视频 / 拆分镜 / 逐镜提示词 / 多段怎么接 | `video-studio` | ✅ |
| 做视频的简易方案 / 数字人 / 生视频路线 | `copy-video-studio` | ⚠️ 旧版，视频相关逐步迁到 `video-studio` |
| 招主播 → 写文案 → 出视频，一条龙 | 依次交给 `live-media-ops` → `copy-video-studio` → `video-studio` | ✅ |
| 账号定位 / 人设 / 赛道选择 | 无 | ❌ |
| 选题 / 追热点 / 对标账号拆解 | 无 | ❌ |
| 直播执行：排品 / 场控 / 憋单 / 话术节奏 | 无 | ❌ |
| 投流：千川 / 随心推 / ROI | 无 | ❌ |
| 涨粉 / 私域 / 企微承接 | 无 | ❌ |
| 数据复盘：场观 / 停留 / 转化漏斗 | 无 | ❌ |
| 剪辑 / 封面 / 包装 | 无（video-gen 只到 brief） | ❌ |
| 平台规则 / 广告法合规 | `live-media-ops` 的合规红线（部分覆盖） | ⚠️ |

> 这张表是**单一事实源**。以后新增技能，先改这张表，再改技能本身。

## 第三步：有技能就交，没技能就说清楚

**有技能**：一句话交接，把已确认的信息原样带下去。

> 「接下来交给 `copy-video-studio` 写口播：平台抖音，品类美妆，目标成交。」

然后退出，不参与下游执行。

**没技能（缺口）**：

1. 明说：「这块现在没有技能。」
2. 给两条路，让用户选：
   - a. 用通用方法临时做一次（提前说明：质量不保证，不会沉淀下来）
   - b. 建议建一个技能（说清它该含什么）
3. 不替用户选。

**绝不假装会。** 缺口就是缺口，说清楚比糊过去值钱。

## 分派硬规则

1. **只分一次**。分完退出，不抢下游的活。
2. **不重复问**。用户说过的平台、品类、目标，原样带下去。
3. **一次只问一个必要问题**，问到能动手就停。
4. **不替用户做业务决定**。赛道选哪个、定位怎么定——给选项和理由，拍板是他的。
5. **领域外不硬接。**
6. **不吹能力。** 做不到的事当场说，别等交付时才发现。

## 信息不够时，按这个顺序问

问到能动手就停，别一次列五个：

1. **平台** —— 抖音 / 快手 / 视频号 / 小红书 / 其他（决定一切）
2. **品类 / 内容方向** —— 美妆 / 服饰 / 食品 / 知识 / 本地生活
3. **目标** —— 涨粉 / 成交 / 品牌曝光 / 私域
4. **现状** —— 有没有账号、多少粉、几个人在做
