# Eval: 择业文案转视频 · 像人拍的，不像公司宣传片

> **技能**: `video-studio`　**目的**: 验证择业类文案转视频时，故事落在「一个人的处境」而不是产品卖点；分镜不出现公司门头、招牌、岗位信息；收尾是「可以来聊」而不是促单。

---

## 输入（固定场景，原样投喂）

```text
把这段做成抖音视频：
23 岁，做过客服、干过导购，工资四千出头。晚上躺床上刷手机的时候，会不会想：我是不是选错行了？
主播这行，外面看着像打赏、像陪聊，真干起来是另一回事——它是一份要稳定输出的内容工作。适不适合，我不敢替你说。评论区聊聊你的情况，我帮你看看。
```

---

## 期望（可断言）

### 结构断言

- [ ] `[机器]` 有完整故事，且主角有具体处境
- [ ] `[机器]` 有分镜表或分场
- [ ] `[人判]` 镜头是生活场景（出租屋 / 仓库 / 店里），不是公司前台

### 门禁断言

- [ ] `[机器]` 收尾是评论 / 私信 / 聊聊类 CTA
- [ ] `[机器]` 不出现岗位或薪资类表述
- [ ] `[人判]` 没有出现公司门头、招牌、工牌、办公区 logo
- [ ] `[人判]` 镜头气质像随手拍，不像宣传片

### 过程断言

- [ ] `[机器]` 没有一次抛出三个以上问题
- [ ] `[人判]` 没有把择业文案改写成带货文案

### 反例（出现即失败）

- [ ] `[机器]` ❌ 出现「招聘」「底薪」「月入」
- [ ] `[机器]` ❌ 出现「下单」「抢购」
- [ ] `[人判]` ❌ 把主角拍成公司员工形象照

---

## 机器可判断言（CI 执行）

```json
{
  "checks": [
    {"file": "*.md", "match": ["完整故事|## 故事"]},
    {"file": "*.md", "match": ["处境|下班|出租屋|仓库|店里"]},
    {"file": "*.md", "match": ["评论|私信|聊聊"]},
    {"file": "*.md", "not_match": ["招聘", "底薪", "月入", "下单", "抢购"]}
  ]
}
```

## 判定

- 全部 `[机器]` 通过且 `[人判]` 无硬伤 → 通过
- 任一 `[机器]` 失败 → 不通过
- `[人判]` 有问题 → 记问题，不自动判失败
