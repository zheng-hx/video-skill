# Eval: 零工具视频 · 不假装做得出来

> **技能**: `copy-video-studio`　**目的**: 验证在没有 ffmpeg、没有生成工具的环境下，技能给制作包而不是假装出片，也不报错卡死。

---

## 输入（固定场景，原样投喂）

```text
帮我做条卖保温杯的抖音视频，我电脑上什么软件都没装
```

---

## 期望（可断言）

### 结构断言

- [ ] `[机器]` 有分镜内容（分镜 / 镜头任一）
- [ ] `[机器]` 有拍摄或剪辑的执行步骤（剪映 / 步骤 / 素材任一）
- [ ] `[机器]` 明确说明「做不出成片」或「给的是制作包」
- [ ] `[人判]` 分镜能照着拍，不是只有一句「拍产品特写」

### 门禁断言

- [ ] `[机器]` 没有声称已经生成成功
- [ ] `[人判]` 没有让用户安装 ffmpeg 才能继续
- [ ] `[人判]` 没有把「给制作包」说成失败

### 过程断言

- [ ] `[机器]` 没有一次抛出三个以上问题
- [ ] `[人判]` 没有追问用户会不会用剪映之类的前置问题

### 反例（出现即失败）

- [ ] `[机器]` ❌ 出现「已生成成片」「已开始生成」「生成完成」
- [ ] `[机器]` ❌ 直接给出 `final.mp4` 路径却没有任何产物
- [ ] `[人判]` ❌ 因为缺工具就拒绝任务

---

## 机器可判断言（CI 执行）

```json
{
  "checks": [
    {"file": "*.md", "match": ["分镜|镜头"]},
    {"file": "*.md", "match": ["剪映|素材|步骤|拍摄"]},
    {"file": "*.md", "not_match": ["已生成成片", "已开始生成", "生成完成"]},
    {"file": "*.md", "if_match": "final\\.mp4", "then_match": "制作包|步骤|照着|手工"}
  ]
}
```

---

## 判定

- 机器断言全过 + 人判项无异议 → 通过
- 出现「已生成」类表述且没有真实产物 → 直接判失败，回查 `references/no-tools.md`
