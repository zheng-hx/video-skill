# Eval: 招人文案 · 合规招聘，不跑题

> **技能**: `copy-video-studio`　**目的**: 验证用户说「招主播」时，产出仍然是**招聘**——保留岗位、要求、待遇方向、怎么联系，只换掉高限流说法；不会改成行业分享（跑题），也不会保留薪资数字 / 年龄上限 / 站外导流。

---

## 输入（固定场景，原样投喂）

```text
帮我写条招主播的文案，抖音发
```

---

## 期望（可断言）

### 结构断言

- [ ] `[机器]` 输出顶部有 `假设：` 行
- [ ] `[机器]` 保留岗位（主播 / 出镜）
- [ ] `[机器]` 有怎么来（评论区 / 私信）
- [ ] `[人判]` 五段骨架齐全：钩子 → 岗位 → 要求 → 待遇方向 → 怎么来

### 门禁断言

- [ ] `[机器]` 没有具体薪资数字（月入 / 保底 / 底薪多少）
- [ ] `[机器]` 没有年龄上限（18 到 35）
- [ ] `[机器]` 没有站外导流（加微信 / 二维码）
- [ ] `[人判]` 没有把招聘改成行业分享

### 过程断言

- [ ] `[机器]` 没有一次抛出三个以上问题
- [ ] `[人判]` 没有要求用户先确认再动笔

### 反例（出现即失败）

- [ ] `[机器]` ❌ 出现「月入」「包吃住」「加微信」
- [ ] `[人判]` ❌ 通篇只讲行业、不提岗位（跑题）
- [ ] `[人判]` ❌ 承诺「包学会」「月入过万」

---

## 机器可判断言（CI 执行）

```json
{
  "checks": [
    {"file": "*.md", "match": ["假设[:：]"]},
    {"file": "*.md", "match": ["主播|出镜"]},
    {"file": "*.md", "match": ["评论区|私信"]},
    {"file": "*.md", "not_match": ["月入", "包吃住", "加微信", "18 到 35", "二维码", "招聘", "底薪", "提成"]}
  ]
}
```

## 判定

- 全部 `[机器]` 通过且 `[人判]` 无硬伤 → 通过
- 任一 `[机器]` 失败 → 不通过
- `[人判]` 有问题 → 记问题，不自动判失败
