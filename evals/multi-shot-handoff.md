# Eval: 多段视频 · 衔接合同和收尾都要有

> **技能**: `video-studio`　**目的**: 验证要拆多段时，每个非最后镜头有 handoff、首尾状态写成可见事实、最后一段有 ending；不出现「保持连续」这种空话，也不把 30 秒硬压成一条。

---

## 输入（固定场景，原样投喂）

```text
这段文案帮我做成 30 秒视频：熬夜脸发黄？每天早上五分钟，洗把脸涂上它，气色肉眼可见地亮。28 天实测，黄气少了三成。点左下角，今天下单送小样。抖音，真人风格。
```

---

## 期望（可断言）

### 结构断言

- [ ] `[机器]` 输出里有分镜表或多段提示词
- [ ] `[机器]` 有 handoff 或衔接说明
- [ ] `[机器]` 有 ending 或落版 / 定格 / CTA
- [ ] `[人判]` 每段的动作能接上上一段的结尾

### 门禁断言

- [ ] `[机器]` 没有「保持连续」「同上」「延续上一镜」
- [ ] `[机器]` handoff 里有 mode（continuous / match_cut / hard_cut / fade）
- [ ] `[人判]` 人物服装、站位在每段一致
- [ ] `[人判]` 最后一段停留 ≥ 1.5 秒

### 过程断言

- [ ] `[机器]` 没有一次抛出三个以上问题
- [ ] `[人判]` 没有把 30 秒硬压成一条

### 反例（出现即失败）

- [ ] `[机器]` ❌ 出现「保持连续」「同上」
- [ ] `[机器]` ❌ 没有收尾（落版 / 定格 / CTA 一个都没有）
- [ ] `[人判]` ❌ 人物换脸或换装没说明

---

## 机器可判断言（CI 执行）

```json
{
  "checks": [
    {"file": "*.md", "match": ["分镜|镜头 s[0-9]|段"]},
    {"file": "*.md", "match": ["handoff|衔接"]},
    {"file": "*.md", "match": ["ending|落版|定格|CTA"]},
    {"file": "*.md", "match": ["continuous|match_cut|hard_cut|fade"]},
    {"file": "*.md", "not_match": ["保持连续", "延续上一镜"]}
  ]
}
```

## 判定

- 全部 `[机器]` 通过且 `[人判]` 无硬伤 → 通过
- 任一 `[机器]` 失败 → 不通过
- `[人判]` 有问题 → 记问题，不自动判失败
