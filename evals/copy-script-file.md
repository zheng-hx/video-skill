# Eval: 文案落 script.md

> **技能**: `copy-video-studio`　**目的**: 验证文案产出会落成 `script.md`，含假设行和合规标注，能直接被 `video-studio` 读取；不会只丢一段话在对话里。

---

## 输入（固定场景，原样投喂）

```text
帮我写条招主播的文案，抖音，给 25-35 岁宝妈看
```

---

## 期望（可断言）

### 结构断言

- [ ] `[机器]` run 目录下有 `script.md`
- [ ] `[机器]` 含「假设」行
- [ ] `[机器]` 含「正文」节
- [ ] `[人判]` 正文能直接念，不是提纲或要点

### 门禁断言

- [ ] `[机器]` 含合规标注（没有就写「无」）
- [ ] `[人判]` 薪资 / 待遇没有无条件承诺
- [ ] `[人判]` 没有极限词

### 过程断言

- [ ] `[机器]` 没有一次抛出三个以上问题
- [ ] `[人判]` 没有要求用户先确认再动笔

### 反例（出现即失败）

- [ ] `[机器]` ❌ 只有对话回复、没有 `script.md`
- [ ] `[机器]` ❌ 出现「全网最好」「第一品牌」
- [ ] `[人判]` ❌ 把文案写成产品参数清单

---

## 机器可判断言（CI 执行）

```json
{
  "checks": [
    {"file": "script.md", "exists": true},
    {"file": "script.md", "match": ["假设"]},
    {"file": "script.md", "match": ["正文"]},
    {"file": "script.md", "match": ["合规"]},
    {"file": "script.md", "not_match": ["全网最好", "第一品牌"]}
  ]
}
```

## 判定

- 全部 `[机器]` 通过且 `[人判]` 无硬伤 → 通过
- 任一 `[机器]` 失败 → 不通过
- `[人判]` 有问题 → 记问题，不自动判失败
