- 类型：故事型

## 正文

孩子上学后的七八个小时，想找点事做吗？

我们在找主播，做带货场，不是打赏陪聊。时间能按你的时段排，孩子放学前后能调。

要求不多：能稳定来，不社恐，愿意学着把话说顺。

收入是固定加分成，具体多少看你播得怎么样，面谈。前三个月有人带。

有意向的，评论区留一句「宝妈」，我私信你。

## 合规标注

- 没写具体薪资数字、没写年龄上限、没写站外联系方式，不做收入承诺。
- 「在找主播」是岗位描述，不构成无条件录用承诺。
