# Eval: 带货文案 · 结构完整且不越合规线

> **技能**: `copy-video-studio`　**目的**: 验证带货类文案五段结构齐全、卖点有支撑，且功效宣称必带合规提示。

---

## 输入（固定场景，原样投喂）

```text
帮我写条带货口播，卖一款保湿面霜，抖音，30 秒
```

---

## 期望（可断言）

### 结构断言

- [ ] `[机器]` 输出顶部有 `假设：` 行
- [ ] `[机器]` 出现明确的行动引导（关注 / 下单 / 点击 / 进直播间任一）
- [ ] `[机器]` 出现具体的使用场景或人群描述
- [ ] `[人判]` 前 3 秒有钩子，不是「大家好我是」

### 门禁断言

- [ ] `[机器]` 提到功效时带合规提示（备案 / 检测 / 资质 / 待确认）
- [ ] `[机器]` 没有绝对化用语
- [ ] `[人判]` 卖点有证据或降级成体验描述，不是空承诺

### 过程断言

- [ ] `[机器]` 没有一次抛出三个以上问题
- [ ] `[人判]` 没有重复问用户已给的平台和时长

### 反例（出现即失败）

- [ ] `[机器]` ❌ 出现「根治」「药妆」「医学护肤」
- [ ] `[机器]` ❌ 出现「最好」「第一」「100%」
- [ ] `[人判]` ❌ 一条文案塞了三个以上 CTA

---

## 机器可判断言（CI 执行）

```json
{
  "checks": [
    {"file": "*.md", "match": ["假设[:：]"]},
    {"file": "*.md", "match": ["关注|下单|点击|进直播间|小黄车"]},
    {"file": "*.md", "not_match": ["根治", "药妆", "医学护肤", "最好", "100%"]},
    {"file": "*.md", "if_match": "保湿|美白|抗皱|修复", "then_match": "备案|检测|资质|待确认|合规"}
  ]
}
```

---

## 判定

- 机器断言全过 + 人判项无异议 → 通过
- 条件断言失败（提了功效却没合规提示）→ 直接判失败，回查 `references/compliance.md` §2
