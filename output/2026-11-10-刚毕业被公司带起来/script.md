# 文案 —— 刚毕业被公司带起来

- 假设：抖音 / 50 秒 / 故事型 / 目标：看完想联系我们
- 骨架：故事型
- 本次讲法：看见别人播 → 自己偷偷试 → 试砸被朋友刷到 → 才被带进门
- 平台 / 时长 / 目标：抖音 / 约 50 秒 / 主动联系

## 正文

刚毕业我在杭州，找了两个月工作没着落，先租了个没窗户的隔断，房租一千八。交完房租水电，一天吃饭二十块。

有天晚上刷到一个女生直播，就坐家里聊天，底下礼物一直飘。我躺床上想：这也能行？

我自己试过。手机架纸箱上，播了半小时，进来三个人走了两个，说句"大家好"就不知道说啥了，自己把直播关了。

过两天朋友发微信：你昨天是不是在直播？我刷到你了。她说你要真想做，来我们公司看看。

我去了。屋子不大，白板上写着"开场三句"，有个姑娘在播，也会卡壳，但底下一直有人聊。

他们没让我交钱，先让我看了三天。第四天让我试，我还是说不出话。他们说，别问好，就说你今天最愁啥。

我说我最愁下个月房租。说完自己都笑了，但那天弹幕真的动了。

练了一个礼拜，我能一个人播一个多小时，没人说话就讲讲今天吃了啥。

现在换了有窗户的房子。我妈生日，我给她买了件外套，她穿上拍照发我，站院子里手都不知道往哪放。

我们公司还在带新人，跟我当时一样，对着镜头不知道说啥。你也这样，评论区说一声。
