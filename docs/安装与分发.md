# 安装与分发

> 装一个入口技能，它把两个技能装到你的机器上。
> **以下命令都在技能目录下执行**（装在哪进哪，比如 `~/.claude/skills/video-design-skills`）。
> 没有编译、没有依赖，只要 Python 3。

## 包结构

```text
skills/video-design-skills/     # 唯一入口
├── SKILL.md                    # 初始化 / 注册 / 诊断
├── capabilities/               # 两个技能：copy-video-studio / video-studio
└── scripts/                    # 渲染与注册
```

## 装到本机

```bash
# 1. 渲染到工作台 ~/.video-design/skills/
python3 scripts/render-package.py

# 2. 注册到探测到的 AI 工具目录
#    Claude Code / Codex / WorkBuddy / Cursor / Trae CN
python3 scripts/reconcile-skills.py
```

`reconcile-skills.py` 只对**已经存在**的工具目录动手，不存在的不建空目录。
软链失败（跨盘等）会自动退回复制。

## 换工作台位置（一般不用）

```bash
python3 scripts/render-package.py --workdir /path/to/wb
python3 scripts/reconcile-skills.py --workdir /path/to/wb
```

## 没有宿主

直接读 `capabilities/<name>/SKILL.md` 照着走。模板在 `assets/`，方法论在 `references/`，
人工照着做也成立。

## 团队分发

```bash
zip -r video-design-skills.zip skills evals docs README.md CHANGELOG.md LICENSE package.json
```

对方解压后按上面两步跑。

## 升级

```bash
python3 scripts/render-package.py --force
python3 scripts/reconcile-skills.py
```

只覆盖技能目录，用户自己的 `output/` 产物不动。
