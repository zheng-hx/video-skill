来深圳一个月了，我还在出租房里躺着。

简历投了三十份，回我的三个，还都是「不合适」。

我一开始真觉得是自己不行。

后来才想明白——不是我不行，是我投的那些岗位，本来就不缺人。客服、前台、文员，一个坑一百个人抢，我的简历排在最后一页，人家根本翻不到。

那在深圳一个月能拿一万多的姑娘，到底在干嘛？

不是坐办公室。

是出镜。

对着镜头说话，讲产品，讲自己每天的日子。有人看，就有收入。不用打卡，不用挤地铁，一台手机一个补光灯就能开工。

还有个事我一直没想通：有些女孩不上班，收入却不低。不是她命好，是她选了个不看学历、只看你能不能坚持的行当。

这行也一样难。前三个月没人看，说话说到嘴干，被弹幕说「不会聊天吧」。但熬过去的人，钱是能看到的。

我躺够了，准备去试试。

想了解这行到底怎么干、一个月到底能拿多少——评论区打「深圳」，我把这半年看到的、踩过的坑整理一份发给你。

先看看，再决定。
