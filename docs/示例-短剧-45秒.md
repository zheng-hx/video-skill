# 剧本 —— 来【城市】一个月的女孩

- 时长：45 秒 / 7 场
- 类型：故事型
- 平台 / 目标：抖音 / 看完来评论区问

## 场景 1：出租房 · 内 · 上午

♪ 窗外偶尔有车声

△ 中景：窗帘拉着，屋里是暗的。她躺在床上刷手机，屏幕上是求职 App。

△ 特写：视频电话弹出来，是妈妈。她把手机举高，只露出脸和天花板。

**她**：（刻意放松）在上班呢，妈，中午休息。

△ 特写：手机被扣在枕头上，屏幕还亮着。

——接场景 2：她翻身坐起来，套上外套出门。

## 场景 2：城市图书馆 · 内 · 上午

♪ 很轻的翻页声

△ 中景：最里面那张桌子，笔记本打开，屏幕上翻着职位列表。

△ 特写：手指点「投递」，屏幕弹「不合适」。她又点，又弹。

**她**：（把手机倒扣在桌上）八年了，没人要。

——接场景 3：傍晚，她回到出租屋。

## 场景 3：出租房阳台 · 外 · 夜

♪ 楼下隐约的车流

△ 中景：她蹲在阳台角落，背靠着洗衣机。

△ 特写：手机屏幕里，一个同龄女孩在客厅直播，边讲边演示。

**她**：（把手机举近）她也不上班啊。

——接场景 4：她回屋，拿了根晾衣杆出来。

## 场景 4：阳台 · 外 · 夜

♪ 静

△ 中景：手机架在晾衣杆上，正对她。她后退半步，挺直背。

**她**：（开口）大家好，我是——

△ 特写：她卡住，捂住脸笑出来。

**她**：（笑着）太傻了。

——接场景 5：第二天早上，同一根晾衣杆。

## 场景 5：阳台 · 外 · 日

♪ 早上鸟叫

△ 中景：她又架起手机，手里拿着一瓶洗洁精。

**她**：（把瓶子举到镜头前）这个，我家用了三年。

△ 特写：她说完愣住，眼睛亮了一下。

——接场景 6：字幕「一个月后」。

## 场景 6：出租房 · 内 · 夜

♪ 轻的电子底噪

△ 中景：茶几上多了补光灯，她坐在前面，看着镜头。

**她**：（笑）今天播到第四场，有人从头留到尾。

——接场景 7：镜头不动。

## 场景 7：出租房 · 内 · 夜

△ 近景：她看着镜头，慢慢笑开。

**她**：我 23 岁，来【城市】一个月，没找到工作。

**她**：现在我能自己挣点饭钱了。你也可以。评论区打『【城市】』，我告诉你我是怎么开始的。

【落版】画面停在笑，叠一行字。
